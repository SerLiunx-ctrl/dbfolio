# 1.0.0-alpha.62

## 中文

- 修复 MySQL BIT(1) 编辑报 Data too long，以及 BIT(8/64) 文本可能被当作 ASCII 数值写入的问题。BIT(1～64) 按真实位宽读取、校验并绑定为精确无符号值，覆盖新增、更新、旧值比较、位主键、删除和单元格详情。
- 修复负数及超过24小时的 TIME 回读，保留微秒；YEAR 明确限制为 0 或 1901～2155；TINYINT(1) 不再因显示宽度被错误限制为布尔值。
- 修复 JSON 旧值比较导致后续更新匹配 0 行的问题；MySQL 原生 JSON 参数正确转换，MariaDB LONGTEXT 不套用原生 JSON 转换。预览与完整读取保留服务器 JSON 原文，避免客户端重序列化改变大数值。
- 网格及单元格提交逐条检查匹配行数；事务表遇到冲突或异常多行时整批回滚，保留待提交修改。
- 行内、详情和粘贴共用字段校验，补齐整数/Decimal 精度与范围、YEAR、JSON 和二进制输入检查；Decimal 不自动舍入，SQLite 数值亲和不误用声明精度限制。不支持的非 NULL 值明确只读，避免伪装成 NULL。

本轮实库验证聚焦本机 MySQL 8.4.6；其他引擎的同名类型保持各自规则。历史错误 BIT 值不能可靠推断原意，不自动批量改写业务数据。

## English

- Fixed Data too long when editing MySQL BIT(1), and text values potentially being stored as ASCII numbers in BIT(8/64). BIT(1–64) now uses exact unsigned values with actual-width validation for inserts, updates, previous-value comparisons, primary keys, deletion, and cell details.
- Fixed reading negative TIME intervals and durations over 24 hours while preserving microseconds. YEAR accepts only 0 or 1901–2155; TINYINT(1) is no longer incorrectly restricted to boolean values by its display width.
- Fixed JSON previous-value comparisons matching zero rows on subsequent updates. Native MySQL JSON parameters use the correct conversion without applying it to MariaDB LONGTEXT. Preview and full-value reads preserve server JSON text instead of reserializing large numbers on the client.
- Grid and cell submissions verify each statement matches exactly one row. For transactional tables, conflicts or unexpectedly broad matches roll back the entire batch and retain pending edits.
- Inline editing, cell details, and paste share validation for integer/Decimal precision and range, YEAR, JSON, and binary values. Decimal values are not silently rounded, and SQLite numeric affinity is not restricted by declared precision. Unsupported non-null values are explicitly read-only rather than presented as NULL.

Live verification focuses on local MySQL 8.4.6; identically named types in other engines retain their own rules. Previously miswritten BIT values cannot be reliably reconstructed and business data is not automatically rewritten.
