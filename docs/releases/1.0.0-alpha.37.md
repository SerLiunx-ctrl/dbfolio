# DBFolio 1.0.0-alpha.37

## 中文

- 修复结构字段类型编辑时下拉列表被单元格裁切、窄列下箭头被输入框挤掉的问题。保留下拉选择和名称/中文说明搜索；列表在独立浮层展示，支持鼠标、键盘及重新展开。修正暗色浮层的背景与文字对比，MySQL、PostgreSQL、SQLite 及建表草稿共用修复。

## English

- Fixed structure field-type dropdowns being clipped by table cells and dropdown arrows being squeezed out in narrow columns. Dropdown selection and name/description search are both retained. The list uses an independent popup with mouse, keyboard, and reopen support. Dark popup colors remain readable. The fix applies to MySQL, PostgreSQL, SQLite, and new-table drafts.
