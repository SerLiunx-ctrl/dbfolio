# 1.0.0-alpha.53

## 中文

- 取消 ER 选表、画布、搜索和保存恢复的表数量限制，支持目录全选。新图加载全部表结构，已保存图恢复原选定范围。
- 取消 AI 关联识别的表数、字段数、结构文本、候选数、标注数及补充说明限制，完整保留注释和关联依据。
- 保留人工选择、重复过滤、字段与结构变更校验；实际规模受模型上下文、输出配置及系统资源影响，共用网络响应与图片导出保护不变。

## English

- Removed table-count limits from ER selection, canvas, search, and saved layouts. Select the entire catalog; new diagrams load all table metadata, while saved diagrams restore their chosen scope.
- Removed ER-specific limits on AI table/column scope, prompt size, candidates, annotations, and instructions. Comments and relationship explanations are preserved in full.
- Manual adoption, duplicate filtering, and column/schema validation remain in place. Actual capacity depends on the model, output settings, and system resources; shared network-response and image-export protections remain unchanged.
