## 中文

- 精简关系型视图页面：普通视图隐藏索引、外键、行写入、触发器、数据生成及无效关联入口；结构页以只读方式展示结果列，信息页隐藏不适用的存储和约束属性。PostgreSQL 物化视图或服务器实际返回的索引仍可查看。
- 表与视图使用不同页签图标；旧页签在读取元数据后同步对象类型，不适用的旧子页自动回到结构页；缺少视图定义时明确提示，避免生成错误的建表 SQL。
- 数据库行右侧新增视图显隐、刷新对象和新建查询图标按钮。显隐按会话和数据库保存，仅影响对象树；点击快捷按钮不会选中或折叠数据库，也不关闭已打开的视图。
- 视图数据页由后端同时禁止网格修改预览/提交，保留查询页显式 SQL 操作。

## English

- Streamlined relational view pages: ordinary views hide indexes, foreign keys, row writes, triggers, data generation and inapplicable relationship actions. Structure shows read-only result columns, and Information omits table-only storage and constraint attributes. PostgreSQL materialized views or actual server-reported indexes remain visible.
- Views have distinct workspace icons. Restored tabs reconcile their object type from metadata, and obsolete subpages fall back to Structure. Missing view definitions show a clear message instead of a fabricated CREATE TABLE statement.
- Added right-aligned database-row icons for showing/hiding views, refreshing objects and opening queries. Visibility is saved per session/database and affects the object tree only. Shortcut clicks do not select/collapse a database or close existing view tabs.
- The backend also blocks grid-change previews and commits for views; explicit SQL operations remain available in the query editor.
