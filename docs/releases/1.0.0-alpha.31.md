# DBFolio 1.0.0-alpha.31

## 中文

- 索引中的列名现在可以点击，直接切换到结构页、滚动定位对应字段并高亮约 3 秒；重复点击可再次定位。
- MySQL、PostgreSQL、SQLite 与新建表草稿共用这一交互，支持鼠标、键盘、只读会话以及包含特殊字符的字段名。
- 定位保留未保存的字段修改；无法对应单个字段的索引表达式保留文本展示，列类型标签与索引编辑保持原有操作。

## English

- Click a column name in an index to open the Structure tab, scroll to the matching field, and highlight it for about three seconds. Repeated clicks locate it again.
- The same interaction works for MySQL, PostgreSQL, SQLite, and new-table drafts, with mouse and keyboard support, read-only sessions, and special characters in column names.
- Navigation preserves unsaved field edits. Index expressions without a matching field remain plain text; type badges and index editing keep their existing behavior.
