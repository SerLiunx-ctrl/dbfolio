## 中文

- AI 服务改为模型配置列表，支持搜索、操作按钮、弹窗新增和编辑、测试、设为默认与删除。
- 模型 ID 优先从服务返回的模型列表选择；获取失败或服务返回空列表时支持手填，已有模型配置保留。
- 新增思考等级、温度和 Top P 配置；默认遵循服务设置，显式配置后作用于共用 AI 请求链路。
- 输出 token 上限由 32768 提高至 128000，并统一前后端校验。实际可用参数与输出额度仍由服务和模型决定。
- 兼容已有模型配置及保存的密钥，关闭未保存表单前支持废弃确认，保存失败保留输入内容。

## English

- Manage AI model configurations in a searchable list with action buttons and dialogs for creating, editing, testing, setting the default, and deleting configurations.
- Select model IDs from the provider's model list. Manual entry is available if fetching fails or the list is empty, while existing model selections are preserved.
- Configure reasoning effort, temperature, and Top P. Unset options preserve server defaults; explicit settings apply to the shared AI request pipeline.
- Raise the configurable output token limit from 32768 to 128000 with matching frontend and backend validation. Available parameters and actual output limits depend on the provider and model.
- Preserve existing configurations and stored credentials. Confirm before discarding unsaved edits, and retain form input when saving fails.
