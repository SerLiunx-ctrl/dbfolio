# 达梦 DDL 验收：1.0.0-alpha.60

日期：2026-11-12。对应设计 R88、用户优先项；完成数保持 5/39，下一规划 R09。本轮范围已交付，源码尚未提交或公开发布。

## 实现范围

- 服务器原生 TABLE/VIEW 定义保留 IDENTITY、CHECK 和存储子句；独立普通/唯一/表达式索引逐个读取原生定义，按 SYSINDEXES.FLAG 系统标识及约束属性过滤系统/支撑索引。
- 根据原生语句中的约束名称及完整子句避免重复附加，匿名主键和 GET_DDL(CONSTRAINT) 的默认 ENABLE 差异有专门处理；不会改写原生特殊索引语句。
- 注释按本对象真实字典元数据生成，正确转义标识符与单引号并保留换行。主定义失败返回空值和原因；单项失败保留其他内容及 ddlWarnings。表页、复制、查询打开与字典导出采用同样的诊断/禁用通用回退规则。
- 查询、分析、DDL、建表、确认 SQL 共用 dameng-sql 高亮和原表/字段补全。其他引擎保留 sql；达梦表标题只显示模式.对象。

## 实库与后端

本机 DM8 8.1.4.80 / 直连 SYSDBA；仅创建本轮专用测试模式，未操作 AGENT 业务对象。

生产适配器、原生 DDL collector、脚本拆分与导入服务的窄测试共 27 项通过。4 个随机源/目标模式、5 个对象、12 条 DDL 回放通过，覆盖 BLOB/CLOB、自增种子和步长、命名与匿名 PK/UQ/CHECK、双向跨模式外键、独立唯一/降序/表达式索引、无索引表、视图、中文引号及换行注释。目标元数据与源一致，并验证 PK/UQ/CHECK/FK 拒绝坏值及级联删除实际生效。

直接使用生产 collector 验证真实服务器错误：主对象缺失时 rawDdl 为空且含失败原因；独立索引读取失败时保留表定义与其他内容并给出诊断，不输出虚构替代定义。

真实探测证据表明，当前 DM8 的 GET_DEPENDENT_DDL(INDEX) 混入系统/约束索引及不适合回放的语句，GET_DEPENDENT_DDL(COMMENT) 缺少字符串引号且列路径不正确；因此未直接使用这些输出。单对象原生索引定义及真实字典注释的组合通过实际回放。

首轮窄测试因 harness 复制模块路径失败，未连接数据库；第二轮重放失败定位为测试工具的模式名替换通过 Token Display 丢失注释引号，已改为按 token span 仅替换 owner 原文范围，保留字符串、注释与外部引用的字节。修复后全量通过，所有失败轮的自有模式均按 finally 清理。

- 达梦 DDL 三主题检查通过：只读、复制与查询打开一致、部分诊断保留、主定义缺失禁用操作、字典不伪造 SQL、标题去重。其他引擎原回退逻辑保持。

## 限制

本轮 DDL 不是完整数据库备份，不包含触发器、授权及外部依赖对象；外键保留真实限定名，需要相应外部对象存在。旧字典快照需重新采集。未把当前 DM8/SYSDBA/非TLS 的测试结果扩展为所有版本、兼容模式、普通角色、SSH/TLS 均通过。
