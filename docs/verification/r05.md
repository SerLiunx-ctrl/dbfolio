# R05 本地配置导入、导出与迁移验收

- 日期：2026-10-18
- 版本：1.0.0-alpha.10
- 状态：已完成；代码尚未提交。

## 支持范围

入口为「首选项 → 配置迁移」。同一入口支持 MySQL / PostgreSQL / SQLite / Redis / MongoDB 会话。按分组或会话选取，支持空分组，以及首选项、收藏 SQL、筛选方案、分析方案、业务关联。环境标记、只读/数据库范围、对象收藏和 SSH/TLS 配置路径随会话迁移。

UTF-8 JSON 格式版本 1；最大 16 MiB、2000 个会话、2000 个分组；每类收藏/筛选/关联最多 10000 项。分析方案沿用 100 个、2 MiB 限制。首选项使用明确白名单，包含界面/布局预设/查询分页/历史保留设置，不复制任意 settings 键。

密码与 SSH 口令不迁移，不读取证书或私钥内容；SQLite、证书、私钥仅保留路径。AI 服务、工作草稿、查询历史、固定页签以及导入导出/同步/数据生成方案不在本项迁移范围。SQL、筛选值及分析参数保持原文，导出界面明确提示分享前检查业务敏感内容。

## 导入语义

- 新建副本：生成新会话 ID，自动避让名称；相关方案 ID 重新分配。
- 合并：按原 ID 或同分组/引擎/名称识别重复，多个目标或连接端点不一致时拒绝；保留本机已有连接、凭据、只读/数据库范围、环境标记和同名方案，追加缺失项。
- 跳过：跳过重复会话及其所有关联项。
- 分组合并去重；选择首选项后覆盖文件中对应键，未包含的本机项保留。
- 预览与执行绑定文件内容/选项/本机相关配置摘要；过期要求重预览。会话及关联配置在同一 SQLite 事务提交。
- 导入前关闭工作标签页、结束任务、断开会话；前端再次检查工作状态、后端检查连接/事务/执行中查询。成功刷新界面，不自动连接或执行 SQL。

## 已执行验证

### Rust

`cargo test`：138 项通过，13 项依赖外部服务的验收未运行。本轮未访问真实业务数据库；配置迁移使用独立临时 SQLite 本地配置库。

专项覆盖：

1. 五种引擎的配置导入/导出往返，中文内容与大整数文本保真。
2. 会话 ID、收藏 SQL、筛选 scope、分析会话、业务关联源、环境标记和对象收藏的重映射。
3. 空环境与已有配置环境；复制新建、重复合并/跳过幂等、保留本机权限范围。
4. 预览期间配置变化拒绝、连接目标冲突拒绝、未知格式版本/缺失依赖/无效结构拒绝；分析名称及关联表/字段长度按前端 UTF-16 规则校验，异常 schema 类型和超量分组在导入前拒绝。
5. 注入中途 SQL 写入错误，验证所有新增会话及已写设置整批回滚。
6. 用随机 ID 的临时 Windows 测试凭据验证合并后密码保留，测试完成自动清理。
7. 白名单导出不携带 AI 配置、工作草稿或凭据；按所选会话限制所有关联方案。
8. 不勾选首选项时保留本机值；本机 JSON 损坏返回错误。
9. 真实 JSON 文件写入/覆盖/读取、中文路径、UTF-8 BOM、损坏文件与超限文件拒绝。
10. SSH/TLS 路径、数据库范围、空分组以及不限标签页/历史保留设置：补充测试通过。
