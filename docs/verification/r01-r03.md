## 可复现命令

```powershell
npm run build
cd src-tauri
cargo test --offline --lib
# 需当前 Windows 用户的已保存本机 MySQL 凭据；不会连接远程会话。
$env:RUST_MIN_STACK = '8388608'
cargo test --offline --lib mysql_r01_r03_roundtrip -- --ignored --nocapture
cd ..
npm run dev -- --host 127.0.0.1 --port 1425
# 另一个终端运行；该 UI 用固定模拟数据，不执行数据库写入。
node scripts/check-mysql-tools.cjs
```

## 明确边界

- 只实测了 MySQL 8.4.6；显示服务器版本与原始错误，其他版本不冒充已验收。
- 导入是逐语句执行，不承诺整文件事务。失败/取消之前的 DDL、自动提交或过程写入可能保留；连接中断不自动重试。
- 导入每条 SQL 最大 64 MiB，预检快照最多 8 份、30 分钟；不支持 SOURCE、shell、客户端连接切换、NO_BACKSLASH_ESCAPES / ANSI_QUOTES 或任意断点续传。
- 对象替换是 DROP + CREATE；MySQL 部分存储程序无法预编译校验，原定义保留在编辑器中供人工恢复。该行为在差异确认区明确提示。
- 依赖和限定名称映射是静态处理；不改字符串内动态 SQL，与源库同名的显式别名会阻止映射。不自动重写外部数据库引用。
- 过程最多保留 20 组、每组 200 行、8 MiB 结果；大字段沿用只读预览。驱动不暴露空结果集完整列定义。
- ZIP 先解压；拆分文件按照 manifest 和文件编号导入。事件按定义恢复，实际运行仍受目标服务器调度器及权限控制。
