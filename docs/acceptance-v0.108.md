# v0.108：生成过程、实时预览与失败提示

## 自行验收

1. 在数据生成页读取结构，选择服务和模型。默认勾选“流式接收并实时显示”。填写要求后点击“AI 直接生成数据”。
2. 过程面板应立即打开：等待响应时显示耗时、处理行区间；收到内容后左侧持续追加返回文本；每批最多 10 条完整返回且校验后，右侧追加通过校验的样本。
3. 点击“暂停跟随”查看较早文本，点击“跟随最新”恢复。点击“收起，后台继续”可回到配置页面，用“查看生成过程”再次展开。
4. 生成成功：收到成功通知，面板显示成功状态及已校验总数。点击“查看完整预览”查看、导出或单独确认写入。生成过程本身不写入数据库。
5. 构造重复名称：在唯一名称列选择固定值，生成两条。应在第二条停止，醒目显示行号、唯一索引及字段，展开显示出错数据；第一条通过校验的样本仍保留。不要使用业务库实际写入验证此项。
6. 服务断开、返回错误格式或输出被截断：显示具体原因、保留收到的文本；不得显示成功或提供失败批次的写入按钮。
7. 生成途中停止：应显示“生成已停止”，已接收内容继续可见，不再请求下一批；没有写入数据。
8. 服务不支持流式参数时，关闭该选项后重试。该模式显示请求等待及每批完整响应，不模拟逐字流。若服务忽略流式参数直接返回 JSON，也会按完整响应处理。
9. 缺少服务/要求、非法数量等本地配置错误，应显示独立原因弹窗、通知及醒目的页面提示；关闭弹窗后配置仍保留。

## 展示边界

- 当前批次文本保留末尾 65536 个字符；前 100 条已校验样本每个单元格最多 500 字符；出错行 JSON 最多 32768 个字符。完整成功数据在最终预览页查看。
- 过程数据只留在当前打开的生成页；重新生成会替换旧现场，关闭页签或重启不恢复流式内容。
- 字符数是传输进度，不是 token 用量；token 仅显示服务实际报告的数字。流失败时不估算未返回的用量。
- 唯一性检查并不自动读取数据库已有记录。后续 AI 批次收到的排重上下文只包含本次已生成的唯一值；相同名称依然可能重复，仍须校验。提示词总大小保持 128 KiB 上限。
- 取消写入与取消生成不同：已经提交的写入不回滚，结果页会显示实际提交数量。

## 自动验证

- 54 项 Rust 测试通过、4 项显式集成测试跳过；覆盖 SSE 分片中文、CRLF/心跳/用量、真实 HTTP 首段即时回调、取消、截断拒收和重复值失败现场。
- 前端回归覆盖有限缓冲、已校验样本、错误行、迟到事件隔离，以及规则转换、模板库、草稿恢复和任务运行逻辑。
- 未调用用户真实模型、未操作桌面；实际服务兼容性与视觉验收由用户完成。
