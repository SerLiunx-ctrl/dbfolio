# DBFolio 1.0.0-alpha.46

## 中文

- 新增 MariaDB 首批兼容：连接选项合并为 MySQL / MariaDB，连接后自动识别 MariaDB；按服务器版本提供 UUID、IP、JSON 和向量类型。
- 修复含隐藏列等厂商扩展时其他普通列无法编辑的问题；保留服务器默认值、生成列表达式及 JSON 校验定义。特殊属性无法安全往返时提供明确提示。
- 特殊索引增加属性保护；MariaDB 向量 SQL 导出使用二进制字面量，避免文本转换损坏数据。
- 同步限制为同厂商，明确阻止 MySQL 与 MariaDB 混合同步。新增可复用 Docker Compose 和兼容范围说明。

- 修复 MariaDB 存储引擎列表为空、JSON CHECK 属性顺序与字段改名引用；修复 MySQL 协议元数据语句被错误分页包装。

## English

- Added initial MariaDB support through the shared MySQL / MariaDB connection option, automatic server identification, and version-aware UUID, IP, JSON, and vector types.
- Fixed ordinary column editing being blocked by unrelated vendor-specific definitions such as invisible columns. Server defaults, generated expressions, and JSON checks are preserved; unsupported target attributes receive a clear SQL-management message.
- Protected special index attributes against lossy visual rebuilding. MariaDB vectors are exported as binary literals to avoid text conversion damage.
- Restricted synchronization to the same server family, explicitly rejecting mixed MySQL/MariaDB endpoints. Added reusable Docker Compose configuration and compatibility documentation.

- Fixed empty MariaDB storage-engine lists, JSON CHECK ordering and renamed column references, and invalid pagination wrapping of MySQL-protocol metadata statements.
