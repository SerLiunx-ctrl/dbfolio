# DBFolio 1.0.0-alpha.28

本次预览版汇总 alpha.21 之后的改动，提供 Windows x64 安装包与完整目录式便携版。

## 类型选择与说明

- MySQL 按服务器版本筛选类型与时间精度；PostgreSQL 按当前数据库实际注册的内置、扩展及自定义类型提供选项。
- 当前数据库已启用 pgvector 时，可选择 vector、halfvec、sparsevec 并填写维度，兼容非 public Schema，标明扩展名称和版本。
- 类型名称后增加中文说明。新增列、行内改列、新建表及旧字段编辑入口使用同一份类型目录，支持刷新、切库与失败降级。

## PostgreSQL 结构兼容

- 修复 DDL 参数命名不一致引发的索引、外键请求失败，共用 MySQL 接口同步修正。
- 外键保留引用 Schema，区分不同 Schema 下的同名表；引用列联动选择。
- 修正带引号名称的大小写判断，补齐索引方法、方向和原始定义。
- PostgreSQL 结构变更使用事务，索引或外键替换失败时保留旧对象。特殊索引保留原始 DDL，通过 SQL 管理，避免简化重建丢失属性。

## 界面与日常操作

- 索引、外键和建表草稿以正文列名与彩色类型标签区分，保持紧凑展示。
- 编辑已有会话保存后保持当前会话和页签。
- SQL 自动补全完整替换已有名称及引用符，避免重复引号、旧名称残留，并保护字符串和注释。
- 数据列最终保留按字段类型设置初始宽度与最小宽度的规则。

## 验证与下载

- PG17/18 与 pgvector 完成隔离实库验证，163 项 Rust 常规回归及三引擎界面、主题/缩放检查通过。
- 安装包与完整便携版通过启动、资源、签名和 SHA256 校验。MySQL/MariaDB 的历史版本规则已测试，尚未逐版本实库覆盖；数组、复杂扩展参数及专属向量索引仍通过 SQL 管理。
- 安装版下载 `windows_x64_setup.exe`；便携版下载并完整解压 `windows_x64_portable.zip`，保留 EXE 同目录的 `web/`。
- 在线更新请选择“预览版”通道。完整跨版本安装升级验收仍在继续，本次不把发布、下载或验签通过等同于全部升级场景通过。
