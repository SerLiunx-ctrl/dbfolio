# DBFolio 1.0.0-alpha.18

发布日期：2026-10-25。本版包含 alpha.17 的数值编辑修复与 alpha.18 的筛选条件改进。

## 筛选条件独立启停

- 每条筛选条件新增「启用」复选框，暂时不用的条件可取消勾选，字段、关系和值继续保留，也可继续编辑。
- 点击「应用筛选」后，仅启用条件参与 AND/OR；全部停用时查看全部数据。筛选按钮显示启用数/总数。
- 保存、载入筛选方案和配置导出/导入均保留启用状态；旧方案默认全部启用。删除与清空功能继续保留。
- MySQL、PostgreSQL、SQLite 的表/视图数据页使用相同交互。

## 数值单元格编辑修复

- 修复双击编辑时整数格式转换失败后按字符串提交的问题，支持数值首尾空白与整数正号，并按字段位宽检查范围。
- 无符号整数使用正确的参数类型；大整数与 Decimal 保留精度，非法数值会提示并保留原值。
- 双击编辑、粘贴及完整值编辑统一依据字段类型转换，覆盖 NULL 改为数值的情形；粘贴先验证整批，避免部分修改。
- 文本字段中的 `0012` 继续保留为文本。

## 下载与更新

- Windows x64 提供 NSIS 安装包和完整目录式便携 ZIP，以及各自的 SHA256SUMS 和更新签名。
- 便携版请完整解压，保留 EXE 同目录的 `web/`；更新时程序与资源必须来自同一版本。会话、首选项和数据库文件保留在原位置。
- 已使用支持在线更新的版本时，可在「帮助 → 检查更新」选择预览通道检查新版。alpha.14 及更早版本需手动安装；alpha.15 存在启动缺陷，建议手动升级。

## 验证范围

- TypeScript、前端生产构建、三种关系型数据库的界面/IPC 回归通过；SQLite 隔离数据库验证实际数值写入和筛选查询，配置迁移往返通过。
- Rust 回归 159 项通过，18 项依赖环境的测试跳过；MySQL/PostgreSQL 本轮未新增真实服务端写入/查询验收。
- 正式安装包和便携版正常启动、107 条校验、105 个 ZIP 文件、101 项资源一致性、签名与篡改拒绝验收通过。
- 完整跨版本安装/重启及隔离 NSIS 升级仍按 [R06 验收记录](../verification/r06.md) 跟进。
