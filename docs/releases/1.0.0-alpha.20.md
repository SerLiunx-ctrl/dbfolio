# DBFolio 1.0.0-alpha.20

## 界面统一优化

- OLED 内容区保留纯黑，菜单、筛选、弹窗等浮层增加独立表面和边界；未选中复选框和禁用状态更容易辨认。
- 页签优先展示名称，数据库信息弱化；保留横向滚动与换行偏好，限制换行栏高度并自动定位当前页签。全部页签菜单分开显示名称与数据库。
- 数据表与查询结果按类型及少量内容样本分配初始列宽，短状态列收紧，代码与长文本更宽；刷新不覆盖手动列宽。索引、外键列布局同步优化。
- 新配置减少会话区默认占比；同侧停靠时可快速收起会话区，展开恢复原比例，已有布局不被覆盖。
- 表工具栏明确区分刷新数据与刷新元数据，少用操作归入更多菜单。DDL 可直接复制或打开为查询草稿，不会自动执行。
- 外观优先显示配色、强调色与动效，九种风格按需展开，预览跟随亮色、暗色与 OLED。

## 精度修复

- 修复大整数自增值进入前端后被舍入的问题，例如 `1919654707669256368` 不再显示为 `1919654707669256400`。
- MySQL、PostgreSQL、SQLite 自增元数据统一使用精确十进制字符串；修改其他表属性时不附带未修改的自增值。

## 同时包含

- 首选项分组与搜索、简洁更新页、关于页面的版本与更新摘要。
- 关于弹窗关闭时尺寸跳变修复。

## 验证与交付

- 三引擎隔离 UI 交互、DDL 草稿、列宽与侧栏恢复、浅色/OLED 及缩放回归；真实 SQLite 内存库与 64 位整数边界验证。
- Windows x64 NSIS 安装包、完整便携目录和 ZIP，各附独立 SHA256 清单。
- 本版未自动公开发布；R06 完整跨版本升级验收仍单独跟进。
