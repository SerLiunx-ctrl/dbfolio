# DBFolio 1.0.0-alpha.16

## 启动修复

- 修复 alpha.15 在线更新插件缺少运行时配置、导致程序启动时直接退出的问题；配置随程序发布，开发与正式构建共用，公钥与签名文件保持一致。
- 增加运行时插件配置回归检查，阻止把仅打包器可用的临时配置误当成程序配置。
- 打包验收新增真实启动检查：运行完整 Tauri/插件/本地存储/前端链路，同时确认主窗口可见和前端 IPC 就绪，并观察进程持续运行。
- 启动检查使用全新的本地配置与 WebView2 缓存，关闭时仅处理检查进程，避免影响用户已打开的旧版和会话。

## 安装与更新

安装包与完整目录式便携版同步交付，EXE 与 web 必须来自同一版本。alpha.15 无法启动时请手动运行新版安装包，或完整解压新版便携 ZIP；保留用户原有配置与数据库文件。

本版包含 alpha.15 新增的签名在线更新功能。公开更新索引和隔离安装环境升级仍按 [R06 验收记录](../verification/r06.md) 跟进，不把本次启动修复视为整个 R06 已完成。
