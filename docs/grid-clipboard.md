# 数据页与查询结果的复制、粘贴

## 右键菜单

- 数据页和查询结果使用共用二级菜单：“复制”包含单元格与行复制；“复制 SQL”包含 INSERT 与 UPDATE。
- 可写数据页的“粘贴”包含追加新行与覆盖当前单元格；详情、关联/筛选、复制为新行和设为 NULL 按上下文保留在第一层。
- 子菜单可悬停或点击展开，也支持方向键进入/返回和 Esc 关闭；贴近窗口边缘时调整展开方向。
- 空白处右键仍可操作已选择的行；只读会话、视图和查询结果不提供表写入操作。快捷键、工具栏及数据提交方式保持现有规则。

## 复制行和单元格

- 右键已选中的行：复制当前多选；右键未选中的行：以该行为目标。空白处右键可以继续操作已选择的行。
- “复制行”和 Ctrl+C 按当前可见列顺序复制，可直接粘贴到 Excel。单元格中的换行、Tab、双引号使用标准 TSV 引号规则保留。
- 同一软件进程内复制行时，还保留 NULL、空字符串、大整数、Decimal、字节等原始类型。普通系统文本本身不能区分 NULL 和空字符串。
- 数据页遇到截断预览，会尝试按完整主键补读。无法补读、查询结果已截断或值为只读扩展类型时，明确拒绝不完整的行复制；不会把预览冒充完整数据。

## 追加与覆盖

- **复制为新行（待提交）**：直接把当前行或多选行追加到表尾。
- **粘贴为新行（待提交）**：把剪贴板行追加到表尾，不覆盖已有行。软件复制的行按字段名称匹配；外部 TSV 按当前可见列顺序匹配。
- **粘贴到当前单元格**：从右键单元格开始覆盖可编辑单元格；支持 Excel 多行多列内容。越出已有行列的内容不会自动新增，需要追加时请使用“粘贴为新行”。
- **工具栏粘贴 / Ctrl+V**：软件复制的行追加为新行；其他文本从当前单元格开始覆盖，没有目标单元格时追加。编辑输入框中的 Ctrl+V 保留普通文本编辑行为。
- 新行略过自增和已识别生成列。普通主键值保留且允许在新行中修改；主键、唯一键重复等服务器约束仍需用户调整。
- 全部新增进入现有“提交 / 放弃修改”流程，不会在粘贴时直接写数据库。无主键表可以新增，已有行仍只读；只读会话和视图不能新增。
- 追加前整批解析类型，任一行无效就不追加。读取期间切表、翻页、刷新或目标编辑状态变化时，旧粘贴请求失效。

## 复制 SQL

- 右键进入“复制 SQL”，选择“复制为 INSERT 语句…”或“复制为 UPDATE 语句…”，预览后复制。SQL 不会自动执行。
- 数据页使用当前表；查询结果从服务器的真实表列表选择目标。不猜测 JOIN、别名或表达式归属；结果字段必须匹配实际字段，重复或未知列名会报错。
- INSERT 略过自增和生成列。UPDATE 要求结果包含真实、完整、非空的主键，WHERE 使用本次行快照的主键；SET 略过主键、自增和生成列，重复主键结果会被拒绝。
- MySQL/MariaDB、PostgreSQL、SQLite、达梦使用各自的标识符、文本、位值、二进制和时间字面量规则。未支持的扩展类型、非有限浮点数、无法完整表示的值会明确报错。
- 查询结果复制的行可以切换到字段名称匹配的数据表，再粘贴为新行；查询结果本身不新增直接写库入口。

生成列信息：MySQL/MariaDB、PostgreSQL、SQLite 使用服务器元数据。达梦复制 SQL 额外审查原生 DDL；旧快照或能力未知时在预览中说明。本轮没有扩展为任意生成列的结构编辑支持。SQLite NUMERIC 自身对超精度 Decimal 的存储限制不由复制功能改变。
