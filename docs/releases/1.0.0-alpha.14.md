# DBFolio 1.0.0-alpha.14 改动汇总

日期：2026-10-20。汇总范围：上次已提交的 alpha.9 之后，alpha.10～alpha.14 的全部实现与修复。

## 配置导入、导出与迁移（R05）

- 首选项新增统一配置迁移入口，五种数据库共用；可按会话或分组选择导出范围。
- 支持迁移首选项、收藏 SQL、筛选/分析方案、业务关联及环境标记，导入前预览重复与依赖关系。
- 提供新建副本、合并、跳过策略，重映射本地 ID 并以事务提交；预览过期、文件损坏和提交失败均明确反馈。
- 排除密码、AI 密钥、证书内容、数据库文件及业务数据；SQLite/证书等本地路径需在新环境核对。迁移前检查连接、标签页和后台任务。

## 字段与表结构编辑

- 修复字段名首尾空白导致 MySQL 改名失败；保留名称内部空格及字段既有属性。
- 修复新增列注释缺失，以及 MySQL 特殊引号、反斜杠注释在修改时的转义问题。
- 新增列、修改列与新建表共用字段模型和行内组件，统一保存/废弃、SQL 预览、失败保留草稿与未保存保护。
- 补齐类型长度/精度/集合、可空、默认值、空字符串、自增、无符号、ON UPDATE、索引及注释；按数据库能力显示并联动限制。
- MySQL 字段和索引合并为 ALTER，PostgreSQL/SQLite 的适用操作以事务执行；SQLite 不支持的注释、追加主键/自增及动态默认值有明确限制。

## 数据网格滚动性能

- 表数据与 SQL 结果的普通单元格采用原生文本渲染，仅为图片候选创建图片预览组件。
- 避免为 UUID、日期、日志和 JSON 反复解码 Base64、逐格查找主键及扫描全文。
- 限制网格展示用长文本长度，完整编辑、提交、复制、详情及应用导出保留原值。
- 2560×1440、570 行×20 列合成生产基准中，主线程滚动耗时减少约 16%～19%，布局耗时约 44%～48%，DOM 节点约 36%。这些是本机合成测试结果，未量化真实 WebView2 工作负载的帧率。

## MySQL 迁移脚本

- 查询页支持选中多条 SQL 整体预检，并在独立连接中顺序执行；无需关闭数据库访问范围限制。
- 支持固定字符串及当前库元数据 IF/EXISTS 的 SET/PREPARE/EXECUTE/DEALLOCATE 模式；两个动态分支均执行范围、只读和危险操作检查。
- 修正误导性的多语句报错；错误显示语句编号和起始行，失败后停止后续执行。
- 修复 MySQL 查询中断返回成功值时可能继续执行后续语句的问题，增加显式取消标记。
- 脚本结果禁用分页、服务端排序及重放式导出，避免再次执行写入；复制和快照绘图可用。
- 已完成写入/DDL 不会自动回滚。复杂动态拼接、系统变量、USE、显式事务控制等仍不支持；R13 尚未整体完成。

## 验证与分发

- 最新前端类型检查及生产构建通过；Rust 146 项通过、0 失败、16 项外部服务用例默认忽略。
- 配置迁移、三引擎字段编辑、原文编辑/复制、图片预览/导出、查询脚本等相关界面回归通过。
- MySQL/SQLite 字段改动实库及 MySQL 迁移脚本重复执行、连接隔离、限行、失败停止和取消验证通过。PostgreSQL 字段属性实库验证受本机服务拒绝连接限制，已保留在验收记录中。
- alpha.14 已完成正式 LTO/NSIS 构建，交付安装包、完整 portable 目录与 ZIP，以及两份独立 SHA256SUMS。107 条校验记录与 ZIP 内 105 个文件一致；资源保持 EXE + 外置 web/ 分发。
- 产物位于 `release/1.0.0-alpha.14/`，按仓库忽略规则保留在本机。路线图完成 5/39，下一项 R06；多语言暂缓。
- 发布版本常量直接读取 package.json，避免手写版本字符串遗漏；提交前重新执行正式双包构建和完整性校验。
