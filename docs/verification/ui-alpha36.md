# alpha.36 前四项界面优化验收

日期：2026-10-29。

- 共用可编辑网格区分焦点描边、行选择背景、修改单元格下边线、新增/删除行边线；修改后还原会清除标记。只标记实际变化的字段，保留原有字段颜色。
- MySQL、PostgreSQL、SQLite 的现有表及新建表草稿支持搜索类型名称和说明。选项展示名称与说明两层，收起显示简短类型名；未知搜索不改变声明，不可用类型不能选择。继续使用服务器发现目录及扩展能力，不自动启用扩展。
- 详情工具栏与元数据保持固定，编辑区随面板伸缩；显示可编辑、已修改待提交、只读、读取中及错误状态，恢复原值清除待提交提示。两种停靠、拖动、JSON/十六进制、NULL、无效输入保护和迟到请求回归通过。
- Redis 服务器总数使用数据库元数据，与 SCAN 去重后已加载数、当前前缀过滤数独立展示；未到零游标时提示继续扫描。专项使用服务器总数 125、第一批 1 条、第二批 2 条及前缀筛选 1 条验证，避免把部分扫描数视为总数。
