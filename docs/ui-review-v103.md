# v0.103 UI 梳理与验收

## 实现梳理

| 区域 | 原问题 | 本轮调整 |
|---|---|---|
| SQL / 表工作区 | 标题、工具栏和数据区重复套卡片 | 平面分区、细边线、缩小内边距 |
| 会话与对象浏览器 | 行与控件密度不一致 | 控件、树行和面板头部收紧，保留连接状态与环境标记 |
| 设置 / 表信息 / 同步 | 大块留白，主题预览占空间 | 间距变量统一、缩小主题缩略图 |
| Redis 详情 | 多层标题和大内边距 | 头部、正文与控件收紧 |
| MongoDB | 集合工具单占一行 | 并入标题，查询和详情间距收紧 |
| 新建 / 编辑会话 | 长单列表单 | 双列字段，主机端口成组，窄窗口单列 |
| 建表 / 改列 / 索引 / 外键 | 表单间距独立定义 | 统一密度，类型说明可展开 |
| 导入 / 导出 / 历史 / 快速打开 | 沿用默认弹窗外壳 | 统一标题、滚动正文和底部操作区 |
| SQL 确认 / 未保存提示 / Redis 与 MongoDB 二级确认 | 与主界面风格不统一 | 共用紧凑弹窗规则，保留焦点和确认流程 |
| 单元格编辑器 / 大文本 | 内容长，底部按钮容易出视口 | 限制弹窗高度，正文内部滚动 |
| 右键菜单 / 下拉框 | 条目高度和装饰偏松 | 紧凑条目，保留列表最大高度与滚动 |

## 验收重点

1. 默认紧凑模式；设置 → 布局与缩放 → 界面密度可切换舒适。重启后选择应保留。
2. 在浅色、深色和不同主题下，二级弹窗应跟随应用主题，文字、禁用和危险状态清晰。
3. 会话表单切换 MySQL / PostgreSQL / SQLite / Redis / MongoDB，检查所有字段、错误消息和底部测试连接按钮。
4. 建表多字段、长 SQL 确认、导入预览、大文本详情等，检查正文能滚动，保存/取消可达。
5. 在小窗口与较大缩放下检查换行；极矮窗口允许整个弹窗滚动。
6. Tab / Shift+Tab / Esc 和二级弹窗关闭后的焦点恢复由 Fluent 原有交互负责，应保持可用。
7. 表格行高、编辑器字号、左右停靠宽度和界面缩放应保留用户设置。

本轮仅代码审阅与后台构建/设置回归，没有桌面或视觉自动验收。系统文件对话框仍使用操作系统样式。
