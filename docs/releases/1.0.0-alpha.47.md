## 中文

- 新增 Kafka、RabbitMQ、RocketMQ 会话及统一消息工作区：对象搜索、范围读取、消息详情、测试发送、基础对象管理和诊断。
- 支持已加载消息查找、JSON/JSONL 导出，文本/二进制/空值区分，Offset 精确显示；后台释放预览，限制单次加载容量。
- Kafka 使用原生协议，RabbitMQ 使用 Management API，RocketMQ 使用 Dashboard 2.x。RabbitMQ 诊断取样需确认且只读禁止；写超时/异常确认结果提示核对。完整支持边界见 docs/message-queues.md。

## English

- Added Kafka, RabbitMQ and RocketMQ sessions with a shared message workspace for object search, bounded reads, message details, test publishing, basic management and diagnostics.
- Added loaded-message search and JSON/JSONL export, distinct text/binary/null values and precise offsets. Inactive previews are released and loading is bounded.
- Kafka uses its native protocol; RabbitMQ uses the Management API; RocketMQ uses Dashboard 2.x. RabbitMQ sampling requires confirmation and is blocked in read-only sessions. Uncertain writes require checking the actual result. See docs/message-queues.md for supported scope.
