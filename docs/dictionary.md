# 数据字典

适用：MySQL、PostgreSQL、SQLite 的表与视图。入口位于数据库概览、数据库/表的右键菜单以及表页工具栏，打开独立「数据字典」标签页；同会话、同数据库复用标签页。

## 采集与阅读

- 选择需要整理的对象；不超过 50 个对象的小库默认全部采集，大库先选范围，单次最多 300 个对象、30000 个字段、16 MiB 结构。仅采集元数据，不读取业务行。
- 左侧为已载入对象；搜索匹配对象名、字段名、类型、数据库注释和本地说明。可按业务分组及「仅缺少说明」筛选。
- 右侧提供字段、索引、外键、对象定义页签；表头可调整列宽，偏好与原结构页分开保存。点击字段或索引列可跳转结构页并定位字段。
- 单对象字段每页显示 200 个，字段搜索可定位后续字段；导出始终使用完整对象。未激活标签页不挂载定义编辑器，以减少后台渲染开销。
- 分别显示数据库注释与本地说明，缺少说明指原注释与本地说明都未填写。SQLite 没有原生表/字段注释，可用本地说明补充业务含义。
- 原始定义优先采用适配器返回内容；PostgreSQL 视图通过服务器 `pg_get_viewdef` 还原查询定义，保留普通/物化视图类别；表的缺失定义使用已有统一 DDL 模型重建，并明确注明仅供结构说明参考。它不是完整备份或迁移脚本。
- 采集失败逐对象标记，允许重试；刷新失败保留上次结构和采集时间。不把部分失败视为完整成功。

## 分组与说明

当前对象可填写业务分组和对象说明；字段的本地说明双击或按 Enter 编辑。点击「保存说明」或 Ctrl+S 保存到本机配置库，「废弃」恢复已保存内容，关闭时使用统一未保存保护。

分组与说明不执行 COMMENT/ALTER，不修改数据库，因此只读会话也可使用。键按会话、数据库、schema、对象和字段区分；不存在的字段说明保留在本地，但不混入当前对象导出。损坏的说明记录不会自动覆盖，界面提示并暂禁编辑。单份本地说明限制 2 MiB。首版不接入配置迁移、版本快照或字典差异比较，后两项属于 R09。

## 导出

- 格式：Markdown、HTML、Excel（XLSX）。可导出全部已载入对象，或当前筛选匹配的完整对象；搜索不会只导出部分字段。
- 导出包括引擎、服务器版本、数据库、采集时间、对象类别、分组、数据库注释、本地说明、字段/默认值/属性、索引、外键规则和对象定义。
- 导出包含当前未保存说明时会提示；未保存内容不会因此自动落盘。导出范围内存在采集失败对象时拒绝导出，避免静默遗漏。
- HTML 的数据库内容全部转义，使用限制性 CSP，不执行数据库备注中的 HTML/脚本；Excel 使用普通字符串，不把以 `=` 开头的默认值或说明转换为公式。
- Excel 超出单元格长度限制的长文本拆为续行，并标出续行序号，中文和 Unicode 字符不会截断。文件先写入同目录临时文件，成功后替换；失败不覆盖原文件，单次导出上限 64 MiB。

PostgreSQL 视图定义依据：[官方系统信息函数](https://www.postgresql.org/docs/current/functions-info.html)。
