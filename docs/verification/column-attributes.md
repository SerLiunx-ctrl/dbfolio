# 字段属性完整性验收

版本：1.0.0-alpha.12；日期：2026-10-19。

## 问题与修复

旧新增列行使用独立简化模型，只有名称、类型、部分长度、可空、默认值和注释；数值精度固定 10,0，缺少无符号、自增和 ON UPDATE，空字符串默认值会丢失，直接执行也绕过统一预览与未保存保护。本轮统一共享行编辑组件、草稿模型和建表/新增列 SQL 渲染器。

## 检查矩阵

| 属性/操作 | MySQL | PostgreSQL | SQLite |
|---|---|---|---|
| 字段名 | 双击编辑、首尾空白规范化、后端校验 | 同左 | 同左 |
| 类型与参数 | 长度、数值精度/小数位、enum/set、时间精度 | 长度、numeric 精度/小数位、原生类型 | 保留声明类型和参数，遵循亲和性 |
| 可空 | 勾选，自增/主键不可空 | 同左 | 已有列修改使用事务重建；追加不可空列需要常量默认值 |
| 无符号 | 数值型可勾选，改为非数值型清除 | 不显示 | 不显示 |
| 默认值 | 无、NULL、自定义（含空字符串）、CURRENT_TIMESTAMP | 同左 | 追加列仅支持常量；建表/已有列可设置当前时间 |
| 自动增长 | 整数、每表一列、必须有索引 | 建表/新增整数列使用 IDENTITY；已有列由 SQL 管理 | 建表/已有单列 INTEGER 主键支持；追加列禁用 |
| ON UPDATE | 仅 datetime/timestamp，精度与类型一致 | 不显示 | 不显示 |
| 新增列的键 | 无、主键、普通索引、唯一索引；已有主键时禁选第二主键 | 同左 | 无、普通索引、唯一索引；追加主键禁用 |
| 注释 | 行内编辑，保留引号与反斜杠 | 同左，与添加列事务执行 | 明确提示不支持 |
| 保存/废弃 | 新增与修改统一预览、未保存保护、失败保留草稿 | 同左，列/注释/索引事务执行 | 同左，列/索引失败一起回滚 |

键的选项使用双击激活，默认保持文本显示。修改已有键仍通过索引页与右键菜单管理，未扩展任意 SQL 默认表达式、生成列及单列字符集/排序规则编辑。
