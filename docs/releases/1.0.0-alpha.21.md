# DBFolio 1.0.0-alpha.21

## 分页页脚

- 表数据与查询结果使用统一紧凑页脚，支持首页、上一页、下一页、直接输入页码后按 Enter 或点击跳转。
- 每页可选择 50、100、200、500、1000 或 5000 条；当前页签保留选择，切换条数回到首页，刷新与排序沿用。
- 行范围与耗时集中显示；空表和超出末尾的空页有明确提示。加载时禁用重复操作，失败保留原结果，未保存修改继续受保护。
- 不自动全表统计，总页数未知时不显示估算总数；任意深页跳转可能较慢。多语句脚本不分页，手动事务沿用原连接并保留结束/失效保护。

## 结果对比

- 原「固定为对比基准」收进「结果对比」菜单，支持保存/替换当前页、与基准对比、清除和查看说明。
- 只比较两份已加载页的快照，按选定唯一键识别新增、删除和修改。可用于刷新前后或不同查询/数据库的结果核对，不修改数据库，不代表全表对比，退出程序后清除。
