# DBFolio 1.0.0-alpha.33

## 中文

- 表数据和查询结果新增可停靠的单元格详情，支持底部/右侧切换、拖动或键盘调整尺寸、关闭以及布局记忆。面板按需展开，选中单元格即可连续查看文本、JSON、十六进制和已有图片预览。
- 表数据的详情编辑与网格编辑统一进入待提交，通过原有预览、提交和放弃流程处理，不再由详情单独写数据库。读取完整值后保留完整原值进行冲突校验；数值精度、NULL 与空字符串分别处理，无效输入会保留并阻止提交。
- 表数据与查询结果新增列管理：搜索列名、显示/隐藏、左右冻结、调整顺序和恢复默认；按表或查询列签名保存列宽、顺序、显隐及冻结状态。复制与粘贴遵循当前可见列顺序。
- 修复 JSON 编辑器的工作线程分派，避免查看与格式化 JSON 时出现后台方法缺失错误。
- 只查看长字段时，完整值仅随当前详情保留；实际编辑后才保存提交所需的完整原值，避免连续浏览使网格缓存持续增长。
- MySQL、PostgreSQL、SQLite 使用一致交互；只读会话、无可靠主键、扩展类型和截断查询结果维持适用的只读限制。查询结果不会推断来源表进行完整值补读。

## English

- Table data and query results now offer an on-demand cell inspector docked at the bottom or right. Resize it by dragging or with the keyboard, close it, and retain its position and size. Select cells to browse text, JSON, hexadecimal values, and existing image previews continuously.
- Inspector edits in table data now join the same pending changes as inline edits, using the existing preview, commit, and discard workflow instead of writing directly. Full-value reads retain the complete original for conflict checking. Numeric precision, NULL, and empty strings are preserved; invalid input remains visible and blocks submission.
- Both grids now include column management: search, show/hide, pin left/right, reorder, and restore defaults. Widths, ordering, visibility, and pinning are saved by table or query-column signature. Copy and paste follow the current visible column order.
- Fixed JSON editor worker routing to prevent missing-method errors when viewing and formatting JSON.
- Viewing a large cell retains its full value only in the active inspector. The grid retains the full original for submission only after editing, preventing browsing from continually expanding the grid cache.
- MySQL, PostgreSQL, and SQLite share the same interaction. Read-only sessions, rows without reliable primary keys, extension types, and truncated query results keep their applicable editing restrictions. Query results never infer a source table for full-value retrieval.
