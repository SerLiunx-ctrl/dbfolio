# 达梦 DM8

版本：1.0.0-alpha.60；首批连接实施：2026-11-11，脚本增强：2026-11-12。

## 连接

新建会话，类型选择「达梦 DM8」。填写主机、映射后的端口、用户名与密码。DM 默认端口为 5236；本次本机 Docker 使用 `127.0.0.1:15236`。密码沿用系统凭据管理器，不写入项目。

「默认模式」可留空，使用登录用户的默认模式，例如 SYSDBA。实例名称 DMSERVER 不填入模式栏。达梦的用户、模式和实例不是同一个概念：左侧原来的数据库选择位置展示模式，右键可新建模式；默认删除模式不使用 CASCADE，非空模式需先处理其对象。

使用固定版本的原生异步 Rust 驱动 dm-rust 0.1.1，无需额外安装 ODBC、JDBC、JRE 或达梦客户端。授权文本随安装版与便携版的 `web/licenses/` 交付。

## 本版支持

- 会话创建、测试、连接与只读设置，复用现有凭据和连接诊断。
- 模式、表和视图浏览，表/字段注释、主键、IDENTITY、索引、外键两端及删除/更新规则、原始 DDL。
- 查询、分页、补全、已加载结果查找、网格暂存与提交、按主键删除、手动事务和取消查询。
- 新建表标签页；字段名、类型、可空性、默认值、注释的行内暂存编辑；添加/删除字段及普通索引和外键管理。
- 共用 ER、数据字典和 SQL 结果分析入口。视图按只读对象展示，隐藏不适用的写入、索引和外键操作。
- 共用 CSV/JSON/Excel 结果导出及 CSV 导入入口；新增 SQL 文件导入，原有完整转储生成仍限 MySQL/MariaDB。

数据页的普通导出改为完整字段 SQL，保留筛选与排序，达梦使用独立完整值读取路径，避免把 BLOB/CLOB 预览保存到文件。通用导出也会拒绝其他旧适配器返回的截断值；这类情况会停止保存并提示，不再静默写入部分内容。其他适配器的完整大字段导出仍需后续适配，不将本轮达梦实测结果扩展到所有引擎。

大整数和 Decimal 保留精确值，BIT 按原生布尔/整数值处理；日期、时间、时间戳、字节和 CLOB 使用原生参数写入。长值预览与完整值查看沿用网格交互。带时区值、Interval 和未解码的复杂类型保留只读展示，不把无法解析的值伪装成 NULL 或字符串回写。

## 差异与边界

- 达梦 DDL 可能隐式提交。先生成全部语句；多条结构变更中途失败时提示刷新核对已执行结果，不声称可以整批回滚。数据网格批次使用事务，乐观锁冲突会回滚整批数据修改。写入连接中断时提示结果未确认，不自动重试写入。
- 创建表可设置整数 IDENTITY；已建列的 IDENTITY 属性和列顺序暂通过 SQL 管理。无 UNSIGNED、MySQL 列级 ON UPDATE 等选项。
- 约束关联索引保留约束属性并限制普通索引编辑；主键、特殊索引及复杂列定义通过 SQL 管理。常用类型下拉提供中文说明，允许保留已有原始类型；不承诺覆盖所有自定义类型。
- 达梦模式仍映射既有数据库/schema 元数据槽位，表标题按“模式.表”展示，避免重复模式名；实际 SQL 始终使用模式限定。
- 首版不开放达梦的触发器管理、同步、数据生成、可视化执行计划、SQL 文件转储生成。直接输入的 SQL 仍受账号权限、只读策略及查询页执行范围约束。
- TLS 由服务器协商，支持驱动的 CA 与服务器名校验配置，首版不支持客户端证书认证；保留共用单跳 SSH 配置。此轮实测为本机非 TLS、直连、SYSDBA、原生兼容模式 0，不宣称其他版本、兼容模式、普通角色、SSH 或 TLS 场景均已验收。

## DDL 页面

表和视图首先读取服务器的原生定义，保留 IDENTITY、CHECK、存储选项等达梦属性。表的独立普通/唯一/表达式索引逐个读取原生定义，主键及唯一约束的支撑索引不重复追加；本机实测厂商的整批依赖索引接口会混入系统索引并返回不适合回放的文本，因此按系统索引标识筛选，保持单个原生定义。约束若已包含在主定义中不重复生成。

表/视图和字段注释按本对象的真实元数据生成 COMMENT，安全转义引号并保留中文与换行；本机厂商的依赖注释接口输出缺少必要引号与正确列路径，不能直接使用。原生定义读取失败时显示原因并停用通用重建；单项依赖失败保留其他可用定义并提示，复制、查询打开及字典导出保留诊断。这里是当前对象结构的查看和重建定义，不包含触发器、授权和外部依赖对象，也不等同于完整备份。旧字典快照需重新采集元数据。

查询、DDL、建表预览、分析和确认 SQL 使用同源达梦语法高亮，保留表/字段补全；其他数据库继续使用原 SQL 语言规则。

## SQL 文件与查询脚本

选中达梦会话及目标模式，在「文件 → 导入 SQL 文件」或模式右键菜单进入。选择文件与编码、预检完整脚本、核对模式切换与作用范围，确认后选择报告目录执行。执行使用预检时的固定快照；修改源文件后需要重新预检。默认遇错停止，显式“出错后继续”仅针对已确认的普通语句错误；WHENEVER SQLERROR EXIT 从出现处起优先停止，事务内出错、取消、断线或超时始终停止。完整 JSONL 报告包含语句序号、原始行号、目标模式和结果，不保存 SQL 正文。

识别 DIsql 的 WHENEVER SQLERROR EXIT、SET DEFINE OFF、SET ECHO OFF 等显示指令与 PROMPT。它们不发送到服务器；PROMPT 显示为本地提示。支持独立 / 分隔的触发器、过程、函数和匿名块，程序体内部的分号完整保留。CREATE 存储程序与 DECLARE 块后若还有 SQL，必须使用独立 / 分隔；文件末尾可以直接结束，包含局部子过程时也不会在内部 END; 处提前拆分。不执行 &变量 替换；文件包含、外部命令、连接切换以及 DEFINE、ACCEPT 等客户端操作在预检时明确拒绝。保存点与 ROLLBACK TO 暂不支持。

查询页也支持同连接多语句脚本与完整程序块，Ctrl+Enter 选择当前完整块，:NEW/:OLD 不视为待填写命名参数。客户端提示独立显示；查询失败后不再残留上一次结果或影响行数。查询脚本限制 16 MiB，文件导入采用流式预检，每条/单行 SQL 上限 64 MiB。多语句脚本中的 SET AUTOCOMMIT OFF/ON 映射原生事务；脚本末尾未提交事务回滚，不暗中提交。这些事务设置仅作用于同一次脚本执行，逐条交互请使用查询页事务按钮。默认导入连接自动提交，与 DIsql 的默认关闭自动提交不同，需要整批事务时在同一脚本中显式 SET AUTOCOMMIT OFF，完成后 COMMIT。DDL 仍可能隐式提交。

客户端指令语义参考：[DIsql 常用命令](https://eco.dameng.com/document/dm/zh-cn/pm/common-commands.html)、[DIsql 环境设置](https://eco.dameng.com/document/dm/zh-cn/pm/environment-variable-settings.html)。DBFolio 仅实现上述子集，不是完整 DIsql 终端。

## 验收方式

设置仅用于本机测试的 `DBFOLIO_TEST_DM_PASSWORD` 环境变量，确保 Cargo 在 PATH，执行：

```powershell
node scripts/check-dameng-backend.cjs
node scripts/check-dameng-grid.cjs
node scripts/check-dameng-native.cjs
```

后端脚本使用生产适配器与元数据/DDL 代码进行独立编译，避免为专项验收重复构建整套桌面依赖；未提供密码时跳过实库项。网格脚本检查实际 TypeScript 生成的查询和编辑值；原生脚本需要 Playwright，使用当前版本正式 portable EXE、隔离配置和 WebView。实库测试仅创建带唯一前缀的模式，结束后删除自有对象和测试会话，不修改业务表或原会话配置。

首批连接见[alpha.58 验收](verification/dameng-alpha58.md)；脚本增强见[alpha.59 验收](verification/dameng-import-alpha59.md)，DDL 增强见[alpha.60 验收](verification/dameng-ddl-alpha60.md)。
