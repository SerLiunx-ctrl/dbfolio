# MongoDB M1＋M2 验收（更新至 v0.101）

## 已完成的后台检查

- 前端 TypeScript/Vite 构建；Rust 单元测试（包含 BSON 类型保真、字段顺序、Projection 约束、原文条件及 URI 秘密信息拒绝）。
- `node scripts/check-mongo.cjs`：页签去重、会话/数据库隔离、历史并发保存、收藏与写盘失败保护。
- 工作区、SQL 效率功能、关系型字段类型既有回归。
- v0.101 已使用本机认证 MongoDB 跑通真实集成测试：53 条文档分批 50＋3、完整读取、投影、增删改、重复键、不可变 _id、过期原文冲突、自动生成 _id、字段重排及日期／二进制／嵌套数组／大整数往返。随机测试库已清理，未访问业务集合。
- 实测发现并修复原文条件 `$ROOT` 应为 `$$ROOT`；写入返回值统一 _id 首位，与服务端顺序一致。
- 未控制桌面；Atlas/TLS/副本集与界面交互由后续验收覆盖。

## 用户验收路径

1. 新建会话选择 MongoDB：普通主机默认27017；也可填不带账号密码的 mongodb:// / mongodb+srv:// URI。账号密码独立填写，认证库默认 admin；如果账号不能列库，在“默认数据库”填目标库。
2. 测试连接，再保存并连接。连续点击连接应共用一次连接尝试，三个区域同步显示状态。URI中的密码或令牌选项应被拒绝保存。
3. 对象浏览器选择数据库、搜索集合、收藏集合；也可输入名称打开集合。空集合首次新增文档后创建，刷新列表可见。
4. 默认查询返回最多1000条、每批50条；调整 Filter / Projection（0/1）/ Sort（1/-1），Ctrl+Enter 查询。下一批替换当前批，空闲超过约2分钟后游标过期可重新查询。
5. 表格直接点击整行查看详情，也可 Tab 聚焦后按 Enter／空格；JSON 树点击卡片查看，展开节点不触发重读。检验嵌套数组、字段缺失与 null。Projection 排除 _id 后仅能查看投影，不能编辑；有 _id 时详情重新获取完整原文。会话应显示绿色 MongoDB 叶片图标。
6. 在专用测试集合新增文档，例如：
   ```json
   {
     "title": "类型测试",
     "large": {"$numberLong": "9223372036854775807"},
     "price": {"$numberDecimal": "123.4500"},
     "created": {"$date": {"$numberLong": "1700000000000"}},
     "optional": null,
     "items": [{"name": "A"}, {"count": {"$numberInt": "2"}}]
   }
   ```
   保存后查看、复制、修改再保存，长整数与小数不应变成近似值；已有 _id 修改应被拒绝。
7. 修改文档但不保存，切换文档/查询/关闭页签/断开/退出，确认出现取消、放弃、保存并继续。取消保留草稿，保存失败仍保留内容。
8. 两个客户端读取同一文档；客户端A提交后，客户端B用旧原文保存或删除应提示冲突，不覆盖A。原文检查按MongoDB文档等值语义，不是业务版本号事务锁。
9. 查看提交前原文/新文对照，复制为新文档应有新 _id。删除需要确认。只读会话不能增删改。
10. 写入中断网或超时：显示“结果待确认”，再次提交禁用；先复制草稿、关闭确认框，重新查询核对实际结果。不要把停止等待当作服务器回滚。
11. 历史收藏可恢复查询条件，重启后集合页签与收藏保留；未提交文档内容不会写入本地草稿，异常退出不恢复。

## 可选专用服务集成测试

需可访问的 MongoDB 测试服务，设置 `DW_MONGO_TEST_URI`（不带密码），需要认证时再设置 `DW_MONGO_TEST_USER`、`DW_MONGO_TEST_PASSWORD`。测试仅创建随机 `dw_acceptance_...` 数据库，覆盖分页、类型、投影、增删改、重复键与原文冲突；正常执行结束清理该随机数据库。

```powershell
cargo test --manifest-path src-tauri/Cargo.toml document_crud_cursor_projection_and_conflicts -- --ignored
```

测试进程被中断或断言失败时可能留下随机测试库，请按测试前缀核对后自行清理。不要使用业务数据库作为测试库。

## 本轮边界

不包含聚合管道、索引管理、字段抽样、导入导出、GridFS、Change Streams、完整mongosh或MongoDB同步。UI列表有字段/数组预览上限，完整文档通过详情查看。取消查询可在任务中心发起；文档写入一旦发出，等待实际返回结果或明确标记结果不确定。
