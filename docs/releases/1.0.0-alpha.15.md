# DBFolio 1.0.0-alpha.15

> 本版存在更新插件初始化引起的正常启动崩溃，请使用 alpha.16 修复版。以下保留原功能变更记录。

## 软件更新

- 新增「帮助 → 检查更新」与「首选项 → 软件更新」，共用稳定/预览通道、可关闭自动检查、跳过版本和更新代理。
- 更新下载进入任务中心，显示实际进度并支持取消；下载完成后由用户选择重启安装。
- 更新包与发布元数据均验证签名；版本比较使用 SemVer，拒绝自动降级及稳定通道中的预发布版本。
- 安装前检查运行查询、后台任务、未保存修改和手动事务，保存工作区并备份完整本地配置数据库。
- 安装版通过 NSIS 更新，保留旧 EXE、已验证的 web 和本地配置快照；便携版退出后由独立进程交换完整目录，保留旧版与恢复日志。
- 便携版支持新版就绪确认；打开本地数据前启动失败可恢复旧程序，访问数据后失败不盲目回退或覆盖本地数据库。

## 构建与发布

- 修复覆盖打包时先删除旧资源、随后才发现 EXE 被占用的问题；现在先检查占用并保留旧目录。
- 修复 Windows .NET ZIP 使用反斜杠路径与更新器不兼容的问题。
- 新增加密签名密钥读取、签名更新索引生成、隔离更新进程与真实产物核对脚本。

## 首次使用与当前边界

首个带更新器的版本需要手动安装或完整解压一次。在线分发需要发布者先上传签名安装包和 portable ZIP，再发布更新索引；发布与完整升级验收状态以 R06 验收记录为准。

更新不替换用户自己的 SQLite 文件、远程数据库或 Windows 凭据。新版本访问过本地配置后，恢复旧程序前需核对数据兼容性；安装登记完整回退需要对应原版安装程序。首版不提供差分更新、强制安装或自动删除旧版材料。

详细验证与发布步骤见 [R06 验收记录](../verification/r06.md) 和 [更新发布说明](../../updates/README.md)。
