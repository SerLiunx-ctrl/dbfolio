# v0.105 用户自行验收

本轮只做代码、构建和后台回归，没有操作桌面。使用 release 目录中的 `Data Workbench v0.105.exe`。

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 图标与关于 | 查看标题栏；底部工作区图标 → 关于 | 三块蓝青色面板图标；显示 v0.105、快捷键、配置/日志路径；诊断复制不包含连接凭据 |
| 布局保存 | 两侧调成不同宽度，底部工作区菜单 → 工作区布局，保存一个名称 | 可重新应用、删除；同名拒绝；重启仍能看到保存的布局 |
| 布局撤销 | 切换「左右分栏」后按 Ctrl+Alt+Z | 返回切换前的位置、宽度、比例和折叠状态 |
| 专注模式 | Ctrl+Shift+J 进入，再按一次退出；也测试原先已折叠侧栏的情况 | 临时隐藏两侧面板，退出恢复原状态；重启不保留专注开关 |
| 分隔条 | 连续拖动；拖动中按 Esc；Tab 聚焦后按方向键/Home/End | 拖动平稳，松手保留最终尺寸；Esc 回到开始尺寸；键盘可调整 |
| 页签管理 | 打开足够多页签，点击标签栏最右侧下拉；右键关闭右侧 | 下拉可滚动并定位；关闭遵循可见排序，保留置顶和其他会话的页签 |
| 页签恢复 | 关闭一个 SQL 页签，Ctrl+Shift+T；对有编辑的页签先取消关闭 | 恢复草稿/已保存 SQL；取消关闭不产生恢复记录；明确放弃的内容不会撤销放弃 |
| 本地撤销 | 收藏/取消收藏对象、移动会话分组，再 Ctrl+Alt+Z | 依次撤销这些本地操作；不撤销数据库内容修改 |
| 快速命令 | Ctrl+P，输入 `>` 后搜索「设置」「布局」「任务」 | 展示应用命令并打开对应界面；命令模式不显示数据库对象加载 |
| 对象搜索 | Ctrl+P 空搜索，再输入表名；手动刷新对象索引 | 空搜索立即展示本地结果；输入后才加载对象，缓存 60 秒；刷新可看到新对象 |
| 恢复与任务 | 重启、连接已有会话；执行查询后进入任务中心 | 底栏提示恢复数量；首次选择才加载恢复的工作区；任务能返回发起时页签，已关闭时禁用 |
| 小窗口与主题 | 高缩放、紧凑/舒适、亮/暗主题下打开布局与关于 | 内容内部滚动，关闭按钮可达，文字与操作不重叠 |

## 范围说明

- 页签关闭历史及本地撤销仅保留本次运行最近 20 项。
- 任务定位不保存历史结果快照，也不自动重跑 SQL。
- 未提交的数据库编辑、删除会话/分组和连续尺寸拖动不属于本地撤销范围。
- Windows 可能缓存任务栏旧图标；标题栏与关于页的图标应立即显示新设计。
