# alpha.15～alpha.16 改动汇总与提交归档

归档日期：2026-10-23。当前版本：1.0.0-alpha.16。实现提交：[36c41aa](https://github.com/SerLiunx-ctrl/dbfolio/commit/36c41aa81d39f8a84b80681f1de041643ce3b894)。

## 主要改动

- 新增签名在线更新：帮助菜单与首选项共用检查入口，支持稳定/预览通道、自动检查开关、跳过版本和无认证代理；下载纳入任务中心，显示进度并支持取消。
- 安装版通过 NSIS 更新；便携版由独立进程整体替换 EXE 与 web。安装前处理未保存内容、运行查询、后台任务与事务，保存工作区并创建本地配置快照，保留旧程序和恢复材料。
- 校验更新包与发布元数据签名，绑定版本和下载地址；拒绝降级、路径穿越、重复文件、资源篡改等不一致内容。
- 修复 alpha.15 缺少更新插件运行时配置引起的启动崩溃，补齐配置及公钥一致性回归检查。
- 完善打包：覆盖前检查文件占用并保留旧目录，兼容 Windows ZIP 路径分隔符，增加签名索引生成和真实启动验收。

## 验证与交付

- 前轮完整 Rust 回归 157 项通过、18 项默认跳过，正式签名产物专项单独通过；前端生产构建、更新交互、菜单和任务职责检查通过。
- 已执行正式 `npm run app:build`，交付 `release/1.0.0-alpha.16/` 内的 NSIS 安装包、完整 portable 目录及 ZIP、两份独立 SHA256SUMS 和更新签名。
- 便携版及 NSIS 解包程序均实测可见窗口与前端 IPC 就绪；107 条校验和、105 个 ZIP 文件、101 个 web 资源一致。一次自动关闭超时后，连续两次隔离复查正常启动并正常退出，原始情况保留在验收记录中。
- 2026-10-23 归档前再次核对版本一致性与 107 条 SHA256，均通过。本轮仅补充归档文档，沿用已验证的正式产物。

## 当前边界

R06 的公开更新索引、真实跨版本升级与隔离 NSIS 安装升级仍待验收，保持 5/39 项完成，下一项 R07。提交推送源码不等于已发布 GitHub Release 或启用公开更新索引。
