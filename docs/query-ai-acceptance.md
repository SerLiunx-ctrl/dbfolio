# 智能生成验收（v0.130）

- 查询页点击「智能生成」，原 SQL 区与需求区各占一半，不出现主弹窗；分析 SQL 区同样支持。
- 输入 @ 显示当前库表名与备注；表名后输入点号显示字段和备注，Ctrl+Space 可手动触发。
- 输入需求后点击生成，自动读取相关表结构，使用设置中的默认服务和流式请求；界面没有服务/模型/流式选择。
- 请求期间左侧仍可编辑 SQL；完整生成后自动追加到最新内容末尾，补上分隔符，不覆盖、不执行；SQL 流式预览不显示 JSON 包装。
- AI 提问时面板从底部滑到中央；单选/多选/具体值有效，稍后回答保留选择；回到发起页签可继续回答。
- 服务未配置时有设置入口；元数据失败、接口失败、取消、输出失败能直接看到原因；失败/取消不自动追加。用户明确要求的修改 SQL 可生成，但不会自动执行。
- 收起保留需求与任务；切换数据库清理旧上下文，后台页签不抢占澄清面板。
- 超过 20 张表或大库中无法定位相关表时，要求在需求中引用表，不随机选择；仅发送结构及已有 SQL/需求，不读取数据行。

自动检查：`node scripts/check-query-ai-ui.cjs`；分析回归 `node scripts/check-analysis-ui.cjs`（需 PLAYWRIGHT_MODULE）。脚本使用隔离 IPC 模拟，不写入真实数据库。

- 中间分隔条支持拖动/键盘/双击恢复；停止按钮在顶栏，底部常驻 AI 内容提醒。
- 流式解析检查：`node scripts/check-stream-sql.cjs`；布局检查：`node scripts/check-query-layout.cjs`。
