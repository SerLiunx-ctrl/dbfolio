# 1.0.0-alpha.59

## 中文

- 新增达梦 SQL 文件导入，复用文件选择、编码、完整预检、确认、进度与报告界面，目标按模式展示。执行固定的预检快照，文件随后改变不会悄悄影响执行。
- 正确处理 DIsql 的 WHENEVER SQLERROR EXIT、SET DEFINE/ECHO OFF、PROMPT 和独立 `/` 分隔的触发器等程序块，不再把客户端指令发送到数据库或按内部的分号拆坏触发器。
- 达梦查询页支持同连接执行脚本，保留原始行号与客户端提示；当前语句选择包含完整程序块，`:NEW`/`:OLD` 不再误认成命名参数。脚本未提交事务在结束时回滚，已提交修改与隐式提交的 DDL 保留，连接中断不重试写入。
- 修复查询或分页失败后残留上次结果、影响行数、耗时与分页信息；修复 MySQL 脚本将合法字段名误判为存储程序关键词。
- 文件导入暂不支持 DIsql 交互变量、外部命令、文件包含和连接切换；保存点暂未适配。达梦 SQL 转储生成及专属触发器管理页仍不在本版范围。

## English

- Added DM8 SQL file import using the shared file, encoding, full preflight, confirmation, progress, and report workflow, with schema-based targets. Execution uses the immutable preflight snapshot, so later source-file edits cannot silently change execution.
- Correctly handles DIsql WHENEVER SQLERROR EXIT, SET DEFINE/ECHO OFF, PROMPT, and trigger/program blocks separated by a standalone `/`. Client commands are no longer sent to the database, and internal semicolons no longer split trigger bodies.
- DM8 query tabs now execute scripts on a dedicated connection, preserving source line numbers and client notices. Current-statement selection retains complete program blocks, and `:NEW`/`:OLD` are not treated as named parameters. Uncommitted transactions roll back at the end; committed changes and implicitly committed DDL remain. Interrupted writes are never retried automatically.
- Fixed stale results, affected-row counts, timings, and pagination after execution or paging failures. Fixed MySQL script preflight incorrectly treating valid column names as stored-program keywords.
- Interactive DIsql variables, external commands, included files, connection switching, and savepoints remain unsupported. DM8 SQL dump generation and a dedicated trigger-management page remain outside this release's scope.
