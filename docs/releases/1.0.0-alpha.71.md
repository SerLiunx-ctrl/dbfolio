# 1.0.0-alpha.71

## 中文

- 修复 MySQL 和 MariaDB 的 TIMESTAMP 在数据页及查询结果中显示解析提示的问题，保留会话时间、微秒精度和 NULL。使用正式客户端完成了 MySQL 表格编辑、提交和查询回读验收。
- 对象浏览新增数据库显隐。可搜索、勾选和批量显示或隐藏，并按会话记住选择。支持 MySQL、MariaDB、PostgreSQL、达梦模式、MongoDB 和 Redis 逻辑库。显示偏好应用于对象浏览和搜索，列表遵循会话的数据库访问范围。
- 改进 MySQL 和 MariaDB 会话的元数据查询。限制数据库访问范围时，可用 SHOW 查看范围内的表、列、索引及对象定义。只读模式也支持这些查询，实例级命令继续按会话范围校验。
- 索引页可分行显示复合索引的完整字段名和类型。优化会话编辑中分组和允许列表的排布，拉开导出等任务的进度条与取消按钮间距。
- 官网增加亮色桌面和手机布局，展示 SQL、ER 图、数据分析、AI 助手、Redis、MongoDB 和 RabbitMQ 的客户端界面。
- 本版提供 Windows x64 安装包与便携 ZIP。

## English

- Fixed TIMESTAMP decoding in MySQL and MariaDB table views and query results. Values retain session-local time, microsecond precision, and NULL. MySQL grid editing, commit, and query readback were verified in the packaged desktop client.
- Added per-session database visibility controls to the object browser, with name search, checkboxes, and bulk show or hide. Supported targets include MySQL, MariaDB, PostgreSQL, DM8 schemas, MongoDB, and Redis logical databases. The setting applies to browsing and search, and the list respects the session's database access scope.
- Improved metadata queries for MySQL and MariaDB sessions. Database-scoped sessions can use SHOW to inspect tables, columns, indexes, and object definitions within their scope. These queries also work in read-only mode, and instance-level commands remain subject to session scope checks.
- Composite index columns and types now wrap across lines. The session form keeps the group control and database allowlist on separate rows. Export and other task panels have more space between progress and cancel controls.
- Added a light website layout for desktop and mobile, with client previews of SQL, ER diagrams, data analysis, the AI assistant, Redis, MongoDB, and RabbitMQ.
- This release includes a Windows x64 installer and portable ZIP.
