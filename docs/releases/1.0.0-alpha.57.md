# 1.0.0-alpha.57

## 中文

- 修复“减弱动效”“关闭动效”和系统减少动态效果时，成功、失败等操作通知无法自动消失的问题。动效设置不再禁用通知的不可见计时动画。
- 通知增加小号关闭图标；成功提示默认显示 3 秒，错误和取消提示默认显示 6 秒，保留悬停或键盘聚焦时暂停、离开后继续计时的交互。

## English

- Fixed operation notifications remaining indefinitely when animations are reduced, disabled, or reduced by the system preference. Motion settings no longer disable the invisible notification timer animation.
- Added a compact dismiss button. Success notifications use a 3-second timeout; error and cancellation notifications use 6 seconds. Hovering or focusing a notification pauses its timer, which resumes when the pointer or focus leaves.
