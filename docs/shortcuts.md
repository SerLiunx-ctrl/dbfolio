# 应用快捷键

版本：1.0.0-alpha.43；日期：2026-10-31。

## 配置

首选项 → 快捷键可录入、清空、单项或全部恢复默认，保存/废弃本次草稿。点击按键栏后按组合键；无修饰键的 Delete/Backspace 清空，Esc 取消本次录入。组合重复、Windows 保留按键及保留给编辑器的文本组合会阻止保存。写入失败保留草稿与原绑定；保存后菜单、提示与执行入口共同使用新配置，重开应用仍保留。

所有绑定仅在 DBFolio 窗口内有效，未使用 Tauri 全局快捷键插件或 RegisterHotKey，不在后台监听键盘。Windows 及其它程序可能优先截获系统按键，本软件不接管这些组合。编辑器内建的复制、粘贴、文本撤销、自动补全、查找等继续由编辑器管理；这里可配置的是应用命令。

| 默认键 | 命令 | 范围 |
| --- | --- | --- |
| Ctrl+S | 保存 | 当前编辑工作区 |
| Ctrl+Enter | 执行 | SQL 编辑器、MongoDB 查询输入、Redis 命令输入 |
| Ctrl+Shift+F | 格式化 SQL | 聚焦的 SQL 编辑器 |
| Ctrl+F | 查找已加载数据 | 当前数据网格；编辑器内仍使用自身查找 |
| Ctrl+P | 快速打开与命令搜索 | 应用窗口 |
| Ctrl+Shift+J | 专注模式 | 应用窗口 |
| Ctrl+Shift+T | 重新打开关闭的页签 | 应用窗口 |
| Ctrl+Alt+Z | 撤销本地收藏/分组/布局操作 | 应用窗口 |
| Ctrl+, | 首选项 | 应用窗口 |
| Ctrl+B | 侧栏显隐 | 应用窗口 |
| Ctrl+加号、Ctrl+减号、Ctrl+0 | 放大、缩小、恢复 100% | ER 激活时作用于画布，其余作用于界面 |

## 保存语义

- ER：保存当前布局及业务标注，包含首次默认布局。分析方案：保存本地方案。查询：保存 SQL 文件，未指定路径时沿用文件选择流程，磁盘冲突检查及取消保持原行为。
- 表数据、列修改/新增、表属性、新建表、MySQL 对象、MongoDB 文档、Redis 值：复用当前编辑保护登记与 SQL/变更预览。Ctrl+S 打开「保存当前修改」确认，数据库写入仍需显式确认；生产环境的额外确认保留。不会绕过只读检查。
- 仅匹配当前活动标签页；未结束的手动事务被排除，不会因保存 SQL 文件或其它草稿而提交/回滚事务。导入/导出/生成等仅用于退出保护的任务不当作可保存草稿。
- 保存前让当前普通输入框失焦，显式结束当前页网格编辑，再等待异步变更通知与渲染完成，收集行内编辑的最新值；忙碌状态不重复提交。隐藏页不响应编辑命令；确认弹窗出现时，应用快捷键不会代替确认按钮。

## 持久化边界

配置保存在本地设置 `ui_shortcuts_v1`，不包含密码。损坏或存在冲突的旧配置回退到默认。此新增设置暂未列入 R05 的偏好迁移白名单，跨设备迁移需后续补齐；不影响原有会话/密码迁移。首版不提供多步按键序列或系统级全局热键。
