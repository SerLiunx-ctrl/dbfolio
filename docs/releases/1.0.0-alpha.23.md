# DBFolio 1.0.0-alpha.23

## 会话编辑

- 编辑已有会话并保存后，保留当前会话、页签和首选项位置，不再自动跳到被编辑的会话。
- 新建、复制会话的选择行为及配置更新后的断开保护保留，不会自动重连。

## SQL 自动补全

- 替换完整的表名/字段标识符和已有引用符，修复重复反引号/双引号及旧名称后半段残留。
- MySQL、PostgreSQL、SQLite 保持一致，支持别名字段、库/schema 限定及转义名称；带引号的候选仍可正常筛选并按 Enter 接受。
- 字符串值和注释保持原文；切换数据库后丢弃过期候选。

## 同时包含

- alpha.22 的表数据/查询结果最小列宽取消与手动宽度保留修复。

## 验证与交付

- TypeScript、真实 App 保存位置与三引擎 Monaco 补全回归通过；既有分析页/缩放及 SQL 词法、收藏方案回归通过，使用隔离测试数据。
- 正式 NSIS 安装包、完整便携目录/ZIP 已生成；双包真实启动与前端 IPC、签名/篡改拒绝及 107 条 SHA256 校验通过，ZIP 105 个文件与双包 101 个 web 资源一致。
- 本版尚未公开发布，公开预览通道保持 alpha.21。
