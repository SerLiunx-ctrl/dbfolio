# alpha.33 数据网格工作区验收

日期：2026-10-28。范围为 Navicat 参考建议中的前三项：停靠详情、统一待提交、列管理；不代表 R14/R15 整项完成。

## 已验证

- TypeScript 检查通过。JSON 使用与当前 Monaco 版本匹配的专用工作线程；实际格式化、JSON/十六进制无效输入与修正回归通过，完整检查要求浏览器 pageerror 为空。
- 真实组件浏览器隔离验收覆盖 MySQL、PostgreSQL、SQLite：数值与 Decimal 精度、完整长文本原值、NULL/空字符串、无效缓冲阻止提交与切换、废弃、只读、无主键和截断主键。
- 完整值只在选中详情存活；只查看时网格仍保留短预览，实际修改后才将完整原值加入变更基线。迟到的完整值读取不会覆盖新选中的单元格。
- 使用真实 TableDataPanel 与 DataChangePreview 组件验证：详情不调用 update_cell；输入进入统一 RowChange；预览后调用 grid_commit；模拟并发失败保留变更；成功清除待提交与关闭保护；只有无效输入时也登记保护，放弃能清除。
- 列搜索、显隐、左右冻结、顺序、恢复默认、刷新持久化、迟到设置不覆盖刚完成的用户调整；至少保留一列。表数据与查询结果共用布局操作，复制和粘贴跟随可见列顺序，隐藏列不消耗粘贴位置。
- 浅色、暗色、OLED 与 100%/200% 缩放：底部/右侧、实际指针拖动和方向键调整、关闭、位置记忆；截图核对布局与中文。只挂载当前详情的一个 Monaco 编辑器，关闭释放编辑器。
- 原有三引擎数值边界、无效粘贴原子性、部分提交/失败预览/生产确认、长文本安全显示与完整复制、文本与图片切换通过。
- 图片回归覆盖三引擎/三主题、可见候选补读与并发、只读/查询结果/无主键、迟到刷新、PNG 3200 万像素、9 Mi 字符、原图导出取消/成功/失败和 Blob 回收。
- 设置页版本号、更新/关于、三主题及缩放回归通过。

## 验证边界

浏览器夹具使用应用真实 React/AG Grid/Monaco 组件及模拟 IPC，不连接用户数据库，不读取用户凭据。统一提交流程验证的是请求类型、原值、目标字段、错误保留与界面状态；本轮未重复运行 MySQL/PostgreSQL/SQLite 实库写入回归，后端接口与方言实现没有修改。正式双包启动/签名/资源校验结果在设计文档第 20 节记录，完整安装跨版本升级仍属于待验收的 R06。

查询结果始终只读，不推断其来源进行补读；无可靠主键保持只读。服务端补读超限或扩展类型仍只读。JSON 树、记录表单、筛选摘要、工具栏全面重排和多列排序面板不在本轮范围内。图片原图窗口及导出沿用既有能力，详情内复用现有查看组件。
