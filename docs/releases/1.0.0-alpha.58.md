# 1.0.0-alpha.58

## 中文

- 新增达梦 DM8 会话，使用原生 Rust 驱动，无需额外安装达梦客户端。支持模式/表/视图浏览、查询、分页、数据网格、手动事务、只读保护和取消查询。
- 达梦复用关系型工作区的新建表标签页、字段行内编辑、索引/外键管理、ER 和数据字典；读取原始 DDL、注释、IDENTITY 以及真实外键更新和删除规则。
- 达梦大整数、Decimal、BIT、日期时间、二进制和大文本按原生类型读写；BLOB 预览保留字节，CSV 日期时间按服务器参数类型转换。数据冲突回滚整批网格修改，写入断线提示结果未确认。带时区与复杂值保留只读展示。
- 按达梦的实例/用户/模式语义调整连接与对象操作。DDL 可能隐式提交，会提示刷新核对；首版不开放触发器管理、同步、数据生成、执行计划及 SQL 文件转储/恢复，其他版本与连接安全场景仍需验收。
- 普通数据导出改用完整字段 SQL，保留筛选与排序，不再导出数据页的预览表达式。达梦读取完整大文本与二进制；其他适配器若仍返回截断值，会停止保存并提示，避免生成部分数据文件。
- 包含尚未公开发布的 alpha.57 通知修复：减少/关闭动效时通知仍会自动消失，新增手动关闭按钮，保留悬停和聚焦暂停计时。

## English

- Added DM8 sessions using a native Rust driver, without requiring a separately installed Dameng client. Supports schema/table/view browsing, queries, pagination, data grids, manual transactions, read-only protection, and query cancellation.
- DM8 shares the relational workspace, including new-table tabs, inline column editing, index/foreign-key management, ER diagrams, and the data dictionary. Reads original DDL, comments, IDENTITY metadata, and actual foreign-key update/delete rules.
- Preserves native types for large integers, Decimal, BIT, date/time values, binary data, and large text. BLOB previews retain raw bytes; CSV temporal text uses server-reported parameter types. Grid conflicts roll back the batch; interrupted writes report an unconfirmed outcome. Zoned and complex values remain read-only.
- Connection and object actions follow DM8's instance/user/schema semantics. DDL can commit implicitly and prompts users to refresh and verify partial results. Trigger management, synchronization, data generation, execution plans, and SQL dump/restore are outside this initial scope; other server versions and secure connection scenarios still require verification.
- Regular data exports now query full columns while retaining filters and sorting, rather than exporting table-browser preview expressions. DM8 reads complete large text and binary values. Other adapters that still return truncated values abort with a message instead of creating partial-data files.
- Includes the previously unpublished alpha.57 notification fix: notifications expire with reduced/disabled motion, provide a manual dismiss button, and retain pause-on-hover/focus behavior.
