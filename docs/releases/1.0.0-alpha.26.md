# DBFolio 1.0.0-alpha.26

## PostgreSQL 结构兼容修复

- 修复 DDL 前后端参数命名不一致，解决编辑索引、添加/修改外键请求失败；共用 MySQL 接口同步修正，保留旧参数格式兼容。
- 外键完整保留引用 Schema，区分不同 Schema 的同名表；引用列联动选择，切换目标后清空旧列，丢弃过期响应。
- PostgreSQL 带引号的名称区分大小写，建表和字段改名不再错误判定重名。
- 索引正确显示方法、方向和键列，保留原始索引定义。条件、表达式、INCLUDE、约束及其他特殊索引通过 SQL 管理，避免简易表单丢失属性。
- PostgreSQL 结构变更使用事务，索引/外键替换失败保留旧结构。
- 保留此前的字段类型列宽规则、会话保存定位和 SQL 补全修复。

- 独立 PostgreSQL 16、18 各 6 项实库验收通过：建表/改列、IDENTITY、默认值/注释、跨 Schema 外键、索引元数据、正常替换和失败回滚。
- 162 项 Rust 回归通过；24 项外部服务测试默认忽略，其中 6 项 PG 专项在上述两个隔离服务显式运行。TypeScript、三引擎建表和行内属性、浅色/OLED、缩放与设置页回归通过。
