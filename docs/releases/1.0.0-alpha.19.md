# DBFolio 1.0.0-alpha.19

## 首选项整理

- 设置按「界面与操作」「数据与服务」「应用管理」分组，增加设置搜索。
- 收起尚无内容的设置分类，调整导航密度、标题与分区，保留已有设置和保存方式。
- 新增「关于」入口，与帮助菜单的关于弹窗使用相同的版本与更新摘要。

## 软件更新更简洁

- 默认显示当前版本、主要更新操作和自动检查开关。
- 通道、代理、更新文件夹及检查时间放入可展开的「更新设置」；新版说明按需展开。
- 下载进行中保留进度与取消，完成后用简短状态提示。安装前的未保存修改、运行任务与事务检查继续保留。

## 关于弹窗修复

- 补充当前版本、本版更新摘要及项目链接。
- 修复关闭时弹窗先变宽再消失的问题：关于与布局使用独立弹窗，关闭动画期间宽度和内容保持稳定。

## 验证与交付

- 首选项、关于弹窗与更新流程覆盖亮色/OLED、100%/200% 缩放；按钮、Esc、遮罩关闭逐帧尺寸回归通过。
- 更新检查/下载/取消、跳过提醒、网络错误、任务和未保存修改保护回归通过；Rust 更新插件运行时配置回归通过。
- 提供 Windows x64 NSIS 安装包、完整便携目录/ZIP 和各自校验清单。R06 完整跨版本安装及隔离 NSIS 升级验收另行跟进。
