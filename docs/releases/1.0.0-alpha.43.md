# DBFolio 1.0.0-alpha.43

## 中文

本次相对上一公开版本 **1.0.0-alpha.33**，汇总 alpha.34～43 的改动。

- **ER 关系图：** MySQL、PostgreSQL、SQLite 共用关系图标签页，支持选表、搜索、自动布局、拖动平移、5%～400% 缩放、字段展开与结构定位，区分真实外键和本地业务关联，支持复合键、自引用及 PostgreSQL 跨 schema 对象。布局和标注可保存到本地，支持 SVG、PNG、Mermaid 导出；大库按范围加载。
- **AI 关联识别：** 复用已配置的 AI 服务，选择表并补充业务说明，查看候选字段配对、模型置信度、依据及核对提示。采用前重新核对结构并过滤过期、重复、无效映射；仅发送所选结构，不读取数据行、不自动创建外键。识别设置可折叠，采用、全选及停止固定在顶部，长列表独立滚动。
- **保存与快捷键：** Ctrl+S 接入 ER、SQL 文件及主要编辑工作区，保存前收集行内输入的最新值；数据库修改保留预览与确认，仅保存当前页，不会提交手动事务。首选项支持录入、清空、恢复默认、保存/废弃和冲突检查，菜单提示随绑定更新。全部为应用内按键，不注册系统级全局热键。
- **数据浏览：** 表数据与查询结果支持 Ctrl+F 查找已加载可见列，匹配高亮、计数和循环定位，不查询数据库、不改变服务器筛选或待提交修改。查找、列管理、单元格详情与导入/导出合并为紧凑工具栏；改进焦点、选中、修改及新增/删除行状态，详情工具栏固定并跟随面板伸缩。
- **结构与外键导航：** 外键本地列和引用字段可打开或复用目标结构页并高亮，保留已有未保存编辑，定位请求不重复执行。字段类型下拉支持名称/中文说明搜索，修复窄列箭头挤压、浮层裁切与暗色对比；统一三引擎和建表草稿的编辑高度。表头直接显示常用操作。
- **单元格详情：** 修复切换数值、时间、NULL 字段时误报目标行不存在；普通文本使用纯文本模式，真实 JSON 继续校验，主动格式化 JSON 保留大整数和原始数值表示。
- **Redis：** 搜索、刷新和键操作后更新服务器数据库计数，分别展示服务器总数、已加载数量、前缀筛选数量与扫描完成状态，不再把扫描页或筛选结果当成总键数。
- **更新说明与稳定性：** 更新页渲染 Markdown、提交及 Full Changelog 链接，外链交给系统浏览器，不执行原始 HTML或自动加载外部图片。新增原生桌面状态/资源回收联动及 WebView 渲染异常诊断、确认式恢复入口；未提交编辑、事务和任务不自动丢弃或重放。
- **验证与已知限制：** 三引擎组件、三主题、双缩放及正式包启动/资源/签名检查通过；真实 MySQL 8.4.6 只读元数据和 SQLite 编辑、SQL 文件保存、自定义快捷键与重启恢复通过。PostgreSQL 实库按约定待补验；持续锁屏识别仍不可靠，不能视为长时 OOM 已根治；完整旧版到新版安装/便携升级链路仍待隔离环境验收。ER 布局与新增快捷键设置暂未专门接入跨设备偏好迁移。

## English

This release includes the changes from alpha.34–43 since the previous public release, **1.0.0-alpha.33**.

- **ER diagrams:** Added a shared diagram tab for MySQL, PostgreSQL, and SQLite with table selection, search, automatic layout, panning, 5%–400% zoom, field expansion, and structure navigation. Distinguish physical foreign keys from local business annotations, including composite keys, self-references, and PostgreSQL cross-schema objects. Save layouts and annotations locally, export SVG/PNG/Mermaid, and load large catalogs by scope.
- **AI relationship discovery:** Reuse a configured AI service, select tables, and add business context. Review column pairs, model-assessed confidence, rationale, and verification notes. Adoption rereads the schema and filters stale, duplicate, or invalid mappings. Only selected schema metadata is sent; rows are not read and foreign keys are not created automatically. Settings collapse while adopt, select-all, and stop remain at the top of independently scrolling results.
- **Saving and shortcuts:** Ctrl+S now serves ER diagrams, SQL files, and primary editing workspaces, collecting the final inline value before saving. Database changes retain preview and confirmation, affect the current tab only, and do not commit pending manual transactions. Preferences support recording, clearing, defaults, save/discard, and conflict checks, with synchronized menu hints. Bindings are application-local; no system-wide hotkeys are registered.
- **Data browsing:** Find text in loaded visible columns of table data and query results with Ctrl+F, highlights, counts, and cyclic navigation, without querying the database or changing server filters or pending edits. Find, columns, and cell details share the compact import/export toolbar. Focus, selection, modified cells, and new/deleted rows are clearer; inspector tools stay fixed while the editor resizes with its panel.
- **Structure and foreign-key navigation:** Source and referenced fields open or reuse the correct Structure view with highlighting, retaining unsaved edits and handling each navigation request once. Field-type dropdowns search names and Chinese descriptions, retain their arrows in narrow columns, avoid clipped popups, and remain readable in dark themes. Editor heights are consistent across the three engines and table drafts, with common table actions exposed directly.
- **Cell details:** Fixed false missing-row errors for numeric, temporal, and NULL fields. Ordinary text uses plain-text mode, actual JSON retains validation, and explicit JSON formatting preserves large integers and original numeric representations.
- **Redis:** Searches, refreshes, and key operations update server database counts. Server totals, loaded keys, prefix-filter results, and scan completion are distinguished; scan pages and filtered results are no longer treated as total key counts.
- **Release notes and stability:** Update notes render Markdown, commit links, and Full Changelog links. External links open in the system browser; raw HTML and automatic external image loading are disabled. Added native desktop-state/resource-reclamation integration, WebView renderer diagnostics, and confirmed recovery. Pending edits, transactions, and tasks are not automatically discarded or replayed.
- **Validation and known limits:** Three-engine component, theme/zoom, and formal package startup/resource/signature checks passed, together with live MySQL 8.4.6 read-only metadata and SQLite editing, SQL file saving, custom shortcuts, and reload persistence. Live PostgreSQL acceptance remains deferred as agreed. Sustained lock-state detection is still unreliable, so prolonged-lock OOM is not considered fully resolved. Complete old-to-new installer/portable upgrade acceptance still requires an isolated environment. ER layouts and the new shortcut preference are not yet specifically included in cross-device preference migration.
