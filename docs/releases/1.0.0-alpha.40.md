# DBFolio 1.0.0-alpha.40

## 中文

- 将表数据页的查找、列管理、单元格详情合并到导入/导出所在工具栏，统一显示图标与中文文字，移除关闭查找时多余的空白工具行；查询结果区采用相同布局。窄窗口可在原工具栏内换行。
- 保留 Ctrl+F 与本地查找栏、列布局、详情停靠及待提交保护；打开查找时才显示输入行。工具随所属网格挂载和卸载，锁屏回收后正常恢复。

## English

- Moved Find, Column Management, and Cell Details into the table data import/export toolbar with icons and Chinese text, removing the empty extra toolbar row when search is closed. SQL results use the same layout. Controls wrap within the existing toolbar on narrow windows.
- Preserved Ctrl+F, local search, column layouts, inspector docking, and pending-edit protection. The search input row appears only when opened. Controls mount and unmount with their grid and return after idle resource reclamation.
