# 1.0.0-alpha.64

## 中文

- PostgreSQL 表数据批量编辑遇到并发删除或原值冲突时，整批回滚，提示冲突行并保留草稿。
- XLSX 将超过 15 位的整数按文本写入，保留主键的每一位，并在导出结果中列出受影响的列名。
- 同步比较完成后显示最终源、目标行数。关联记录使用目标表声明的字段类型。新建、编辑和复制网络会话时会在字段旁提示端口错误。
- 改进 200% 缩放时的设置布局、滑块读数、强调色和主按钮的文字对比度。补全历史筛选和网格选择框的中文辅助名称、快速打开空状态、只读菜单文案及关闭关于窗口后的焦点恢复。
- 安装包和便携版均附带离线设计文档及其引用的附件，可从 `web/manual/docs/design.md` 打开。
- 达梦表数据批量提交出现并发冲突时，错误提示具体项与主键，整批回滚并保留编辑。补齐应用菜单、对象树、查询文件、结果对比、建表与表结构菜单的图标。
- 表数据工具栏在窄窗口保持一行，放弃与提交按钮始终显示在右侧；左侧操作可横向滚动，按钮保留图标和文字。

## English

- PostgreSQL table edits now roll back the entire batch on a concurrent deletion or a stale value. The error identifies the conflicting row and keeps the pending edits.
- XLSX exports preserve integers longer than 15 digits as text. The export result lists the affected columns.
- Completed sync comparisons show the final source and target row counts. Related records display the target table’s declared column types. Network session forms flag invalid ports beside the field.
- Improved the settings layout at 200% zoom, slider values, accent previews and primary button contrast. History filters and grid selection controls have Chinese accessible names. Quick Open reports empty results, read-only cells use a view-only menu label, and closing About restores focus to its opener.
- Both Windows packages include the offline design document and linked attachments under `web/manual/docs/design.md`.
- Dameng batch edits now identify the conflicting item and primary key while rolling back the batch and retaining pending edits. Missing icons were added to the application, explorer, query file, result comparison, table creation and table structure menus.
- The table data toolbar stays on one row in narrow windows. Discard and Submit remain visible on the right while left side actions can scroll horizontally with icons and labels intact.
