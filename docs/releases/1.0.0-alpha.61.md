# 1.0.0-alpha.61

## 中文

- 数据页与查询结果右键支持复制为 INSERT / UPDATE：预览后复制，不直接执行。数据页使用当前表，查询结果从真实表列表选择目标；UPDATE 必须包含完整且非空的主键，拒绝重复列、未知别名和重复主键。
- 重整行复制与粘贴：复制行保留单元格内换行、Tab、引号，软件内部还保留 NULL、空字符串、大整数、Decimal 和二进制类型。空白处支持右键，新增“复制为新行”“粘贴为新行”和明确的“粘贴到当前单元格”。Ctrl+V / 工具栏粘贴在剪贴板为软件复制行时追加新行，外部文本仍按当前单元格覆盖；没有焦点时追加。
- 修复单元格引号被当作 TSV 语法剥掉的问题，单元格内 Tab 和换行按原值粘贴；修复 SQLite 空 BLOB 在预览后被误复制为 NULL。
- 新行只进入待提交，不立即写库；略过自增和已识别生成列，普通主键允许修改。无主键表允许新增，已有行继续只读；只读会话与视图不开放新增。异步读取期间刷新、翻页、切表或编辑状态变化时拒绝过期粘贴。
- 四引擎共用类型和 SQL 方言规则，避免截断预览生成不完整 SQL。数据页可按主键补读完整字段，查询结果含截断或只读扩展值时明确拒绝。MySQL/MariaDB、PostgreSQL、SQLite 补充生成列元数据；达梦复制 SQL 结合原生 DDL 识别生成列，未识别能力明确提示。

查询结果复制 SQL 不推断 JOIN / 别名归属；用户需要选择实际目标表并核对约束。跨类型粘贴按目标字段转换；外部 TSV 无法区分 NULL 与空串，只有同一软件进程内的类型化行副本保留该区别。SQLite NUMERIC 对超精度十进制的存储限制仍由数据库决定。

## English

- Added Copy as INSERT / UPDATE to table-data and query-result context menus, with a preview before copying and no immediate execution. Table data uses the current table; query results require choosing a real target table. UPDATE requires a complete non-null primary key and rejects duplicate columns, unknown aliases, and duplicate keys.
- Reworked row copy and paste. TSV preserves embedded line breaks, tabs, and quotes; internal row copies also retain NULL, empty strings, large integers, Decimal, and binary types. Blank areas support context menus with Duplicate as New Rows, Paste as New Rows, and explicit Paste into Current Cell. Ctrl+V / toolbar paste appends internal row copies, while external text overwrites from the current cell or appends when no cell is focused.
- Fixed cell quotes being interpreted as TSV syntax; embedded tabs and line breaks remain one original cell value. Fixed SQLite empty BLOB previews being copied as NULL.
- New rows remain pending until submitted. Auto-increment and identified generated columns are omitted, and ordinary primary keys can be edited in new rows. Tables without primary keys allow insertion while existing rows remain read-only; read-only sessions and views prohibit insertion. Paste operations are rejected if their target changes during asynchronous clipboard reading.
- Shared type and dialect handling covers all four relational engines and prevents incomplete SQL from truncated previews. Table data can load full values using primary keys; query results explicitly reject truncated or unsupported read-only values. Added generated-column metadata for MySQL/MariaDB, PostgreSQL, and SQLite. DM8 SQL copying also inspects native DDL and reports unresolved capabilities.

Query-result copying does not infer JOIN or alias ownership: select the actual target table and review its constraints. Cross-type paste converts values against destination fields. External TSV cannot distinguish NULL from empty strings; only typed row copies within the same application process preserve that distinction. SQLite NUMERIC precision limits remain database behavior.
