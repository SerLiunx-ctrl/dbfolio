# v0.102 验收清单

## 入口

- MongoDB 集合页右上方「集合工具」：统计、索引、字段抽样、聚合、导入导出。
- SQL 查询页「执行计划」：优先选择的文本，否则使用光标所在语句。

## MongoDB（请使用测试集合）

1. 读取统计，检查文档数、字节空间与索引数；无统计权限时应显示错误。
2. 索引页读取列表；创建 {"keys":{"category":1,"createdAt":-1},"options":{"name":"category_created"}}，确认前核对定义，完成后刷新列表。只读会话无法创建索引。
3. 字段抽样应显示抽样数、顶层字段类型与缺失次数；结果不应声称是完整结构。
4. 聚合输入 [{"$group":{"_id":"$category","count":{"$sum":1}}},{"$sort":{"count":-1}}]，执行并展开结果；输入 $out 或 $merge 应被拒绝。结果过多时提示上限。
5. 导出可选 JSON Lines / JSON 数组；Filter 来自文档浏览页当前输入。导出完整匹配文档，忽略 projection 和浏览条数限制；文件保留 ObjectId、日期和长整数包装类型。
6. 在另一测试集合导入文件。导入只新增；再次导入应报告重复键、显示成功与失败数，源文件旁出现唯一错误记录文件。
7. 运行任务时点「收起」，到任务中心查看进度/取消。导出取消保留原目标文件；导入取消保留已提交文档。单条写入正在等待服务器时，取消不会回滚它。
8. JSON 数组大于 64 MiB 时应拒绝；大文件使用 JSON Lines。只读会话可导出，不可导入。

## SQL 执行计划

1. MySQL / PostgreSQL 对带索引查询生成计划，查看表、索引、预估行数与成本；展开子节点和原始 JSON。
2. 无索引查询若计划选择全扫描，应显示提示；提示不代表所有全扫描都应建索引。
3. 多条 SQL 中移动光标，计划应针对当前语句；选中单条时使用选中内容。
4. 不传 ANALYZE，不接受原始 EXPLAIN 或多条语句；SQLite 保持原网格结果。
5. 原始 JSON 格式未识别时仍可查看原文。计划成本为优化器估计，不代表毫秒耗时。

## 后台验证

本轮本机 MongoDB 临时库通过统计/索引/聚合/抽样、两种格式导入导出、BSON 类型往返、重复键报告和导出取消保护验证。SQL 新功能通过语句边界和 PG/MySQL 计划样本测试。本轮未控制桌面，也未对 MySQL/PG 的新计划显示做真实服务验收。
