## 修复范围与原因

- `PROMPT DM8_IMPORT_OK_AGENT` 是 DIsql 客户端输出，原先误发给数据库，导致截图中第 7 列附近的语法错误。WHENEVER、DEFINE/ECHO 等指令也需要与服务器 SQL 分开处理。
- 触发器及程序体内部有分号、IF/END IF 和局部子过程，不能使用普通分号拆分。程序对象与 DECLARE 保留至独立 `/` 或文件末尾，匿名 BEGIN 使用完整块边界。
- MySQL 查询脚本的存储程序预检原来扫描全部关键词，会误判合法字段名；改为识别真实语句头。查询失败后清除旧结果、影响行数、耗时和分页，避免显示旧的“受影响行数 3”。
