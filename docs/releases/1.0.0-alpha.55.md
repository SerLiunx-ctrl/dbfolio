# 1.0.0-alpha.55

## 中文

- **触发器管理**：新增独立页签与闪电图标入口，支持全库/单表搜索、SQL 高亮定义与复制、新增、受支持定义编辑、删除及 Ctrl+S。保存与删除先预览 SQL 并明确确认，草稿提供保存/废弃保护，页签支持恢复。
- **跨库交互与保护**：MySQL/MariaDB、SQLite、PostgreSQL 共用触发器界面，按引擎选择时机、事件、执行粒度或已有触发器函数。复杂定义只读以保留属性；执行前核对原定义，并保留只读、数据库范围和生产会话确认。MySQL/MariaDB 替换不能整体回滚，失败时尝试恢复原定义并报告结果。
- **ER 范围与 AI**：移除 ER 选表、画布、搜索及布局恢复的表数量限制，支持目录全选；移除 ER AI 识别专属的表数、字段数、文本、候选和标注限制，保留完整注释与关联依据。人工采用、重复过滤与结构变化校验继续生效，实际规模取决于模型与系统资源。
- **ER 详情**：修复打开 AI 识别面板后实体/关联详情被隐藏的问题，两者可同时查看并独立关闭。再次点击表头即可收起详情，展开和关闭有轻量动画；支持减少动态效果，拖动表头不会误开关详情。
- **ER 布局**：修复缩放控件重复外框、按钮及边框贴合，统一工具栏和选表底部间距，窄面板可换行；长表名省略并支持悬停查看。
- **任务中心**：进度、提示和返回/复制/取消操作分区，显示真实进度与进行中/已结束数量，运行任务优先；长消息和错误独立滚动，没有结束任务时禁用清除。
- **预览修复**：取消较慢的 SQL 预览后，迟到的旧结果不会再覆盖新预览；修复开发模式首次打开触发器页可能空白的问题。
- **验证范围**：正式 EXE 的 MySQL 8.4.6 与 SQLite 触发器实库和界面验收通过，安装包/便携版资源、启动、校验与签名通过。PostgreSQL 实库依既有安排待补，MariaDB 容器本轮未运行；完整安装升级与长时锁屏识别的既有待验收项仍保留。

## English

- **Trigger management**: Added a dedicated workspace and lightning-icon entry points, with database/table search, highlighted SQL definitions, copy, creation, supported-definition editing, deletion, and Ctrl+S. Save and delete operations require SQL preview and explicit confirmation; drafts support save/discard protection, and tabs can be restored.
- **Consistent interactions and safeguards**: MySQL/MariaDB, SQLite, and PostgreSQL share the trigger interface with engine-specific timing, events, granularity, or existing trigger functions. Complex definitions remain read-only to preserve attributes. Writes recheck the original definition and retain read-only, database-scope, and production confirmation checks. MySQL/MariaDB replacement is non-atomic; failures attempt to restore the original definition and report the outcome.
- **ER scope and AI**: Removed table-count limits from ER selection, canvas, search, and saved layouts, with catalog-wide selection. Removed ER-specific AI limits on tables, columns, text, candidates, and annotations, preserving full comments and relationship explanations. Manual adoption, deduplication, and schema-change checks remain; actual capacity depends on the model and system resources.
- **ER details**: Fixed table and relationship details disappearing while the AI panel was open. Both can be viewed and closed independently. Clicking a table header again collapses details, with lightweight opening/closing transitions, reduced-motion support, and no accidental toggles while dragging.
- **ER layout**: Removed redundant zoom-control frames and touching button borders. Toolbar and table-picker footer spacing is consistent, narrow panels wrap, and long table names show their full text on hover.
- **Task center**: Separated progress, messages, and navigation/copy/cancel actions. Actual progress and active/finished counts are shown, active tasks appear first, long messages/errors scroll independently, and clearing is disabled when no finished tasks exist.
- **Preview fixes**: Late responses from canceled SQL previews no longer overwrite newer previews. Also fixed an empty initial trigger workspace in development mode.
- **Validation scope**: Trigger database and UI checks passed with the production EXE on MySQL 8.4.6 and SQLite, alongside installer/portable resource, startup, checksum, and signature checks. Live PostgreSQL validation remains deferred as previously arranged; the MariaDB container was not running this round. Existing full installation-upgrade and long-lock-screen detection checks remain pending.
