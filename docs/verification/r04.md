## 实库验收

MySQL 8.4.6 使用已保存的 loopback 会话，SSH 为测试进程内的独立服务器：

- TLS require 直连和 SSH 转发均通过。
- 错误密码归为认证失败；不存在的默认库归为库访问失败；错误 TLS 服务器名/证书验证失败归为 TLS。
- 创建随机无权限测试用户，访问 mysql 库被拒绝并归为库访问失败；测试完成删除该账号，未修改现有用户或业务数据。
- PostgreSQL 实库测试尝试时本机拒绝连接；当时 PostgreSQL/Redis/MongoDB 服务未运行，未完成这些引擎的实库直连/SSH 验收。保留各引擎独立 ignored 用例供相应环境执行，不把服务未启动当作通过。

本次满足 R04 单跳连接、TLS、认证/权限错误与资源清理的核心验收；驱动已接入各引擎，但不扩大为所有服务版本、证书算法、集群或操作系统都已验证。

## 行为边界

- 诊断为测试结束后的阶段报告；TLS 与认证由驱动完成联合握手，无法精确拆出全部内部子步骤。
- 默认库访问测试不代表该账号拥有全部表的读写权限；未指定默认库时明确跳过。
- prefer 允许明文回退；需要身份校验使用 verify-full。Redis/MongoDB 单主机 TLS 始终验证身份。
- MongoDB URI/SRV 不支持 SSH 与自定义服务器名，单主机隧道使用 directConnection；URI 客户端证书必须含私钥。
- 不支持多跳、SSH agent、代理链。证书/私钥保存为文件引用，不随程序包复制。
- 查询超时表示停止等待，不承诺服务端撤销；不自动重放写入。隧道守卫不负责重连，断线需用户重新连接会话。
