# alpha.63 测试报告修复验收

2026-11-17，复核 Windows x64 alpha.63 报告中的 14 项问题，修复版本为 alpha.64。

| 项目 | 复核方法与结果 |
|---|---|
| PostgreSQL 并发提交 | 在独立 PostgreSQL 18.6 实例上用两个连接重现旧版部分提交。alpha.64 正式程序中，第二行被删除后提交两行，错误标出第二项和主键；独立连接读回第一行的原值，两份草稿保留。恢复第二行后重试，两行都成功。 |
| XLSX 主键保真 | 在隔离 SQLite 库通过正式导出生成工作簿，再解压核对单元格类型和共享字符串。9007199254740993、9223372036854775807 及负边界按原文保存，42 保持数值，中文与空值正确。CSV、JSON 对照通过。导出界面列出受影响的 id 列，界面专项由测试夹具代选保存路径。 |
| 会话与关联记录 | 端口表单检查空值、1、65535 和六种非法输入；非法输入下测试与保存均无法发起。关联记录组件在 SQLite 和 PostgreSQL 夹具中按列名使用目标表声明，缺少类型时检查回退显示。 |
| SQLite 同步与元数据实库 | 最终 EXE 的同步差异表、确认与最近任务记录分别核对了源/目标 4/1、4/4 和 0/0；扫描到 71,000 行时取消，任务显示“对比已取消”，目标库仍为零行。关联表两个 TEXT 字段分别返回中文值及 NULL，均显示真实声明类型。 |
| 网格交互 | 只读表菜单显示“查看单元格详情”，可写表保留编辑入口。只读表、可写表、查询结果的复选框都有中文名称，并能反映选择状态。 |
| 设置、查找与无障碍 | Edge 测试了两项历史筛选、命令和对象无匹配、两个菜单入口 × 三种关闭方式的焦点恢复；900、1024、1280 宽度各测 100% 和 200%。亮色、暗色、OLED 下用默认蓝及自选黄检查两个窗口，36 次主按钮对比度测量最低 4.68∶1。比例滑块的标签、控件值与保存值相符。 |
| MySQL 回归 | 在独立 MySQL 8.4.6 实例上完成 118 项字段写入及 8 组实库检查，覆盖 BIT(1/64)、负 TIME、JSON 大整数往返及第二项冲突时的整批回滚。 |

读屏语义通过控件可访问树和键盘测试。Narrator/NVDA 实际语音播报、跨显示器 DPI、长时锁屏与跨版本安装升级未纳入本次实测。

最终 EXE 的 SHA256 为 `3c0a65b558ac17986964777088dc9c7defdefb79a196a13f165ca38eef3ce6c2`。安装包和便携包均通过资源自检、隔离启动和前端 IPC 检查。两份清单共 214 项，便携 ZIP 内 212 个文件，安装包与便携包的 208 项前端资源一致；两份离线手册分别核对了 106 个可达文件。包签名、更新元数据验签及篡改拒绝检查通过。收尾核对 src-tauri/target 为 5.09 GiB，C 盘剩余约 359.1 GiB。
