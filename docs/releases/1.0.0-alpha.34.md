# DBFolio 1.0.0-alpha.34

## 中文

- 软件更新页正常渲染 Markdown 更新说明，标题、列表、强调、代码、提交和 Full Changelog 链接不再显示为原始标记；外链使用系统浏览器打开，不执行原始 HTML，也不自动加载外部图片。
- 外键本地列可定位同表结构，引用表和字段可打开或复用目标结构页并短暂高亮。MySQL、PostgreSQL、SQLite、新建表草稿、自引用及只读会话使用一致操作；跨库/Schema 使用准确目标，复用已有页签不会重载或丢失未保存的结构修改。定位请求只处理一次，之后返回页签保留用户选择的子页面。
- 列管理、单元格详情、切换停靠位置和关闭改为带中文提示的图标按钮；增加紧凑的上下内边距，避免按钮紧贴边界。
- 普通文本根据字段类型使用纯文本编辑，不再因为括号、JSON 样式内容或切换前的语言状态触发 JSON 校验；真正的 JSON 字段及 MongoDB 文档继续使用 JSON 模式。主动格式化文本内的有效 JSON 只调整空白，保留大整数和数值原文。

## English

- Software updates now render Markdown release notes with proper headings, lists, emphasis, code, commit links, and Full Changelog links. External links open in the system browser. Raw HTML is not executed, and external images are not loaded automatically.
- Foreign-key source columns navigate to the current table's Structure view. Referenced tables and fields open or reuse the target Structure view and briefly highlight the field. MySQL, PostgreSQL, SQLite, new-table drafts, self-references, and read-only sessions share the interaction. Cross-database/schema targets are preserved, and reusing a tab does not reload or discard unsaved structure edits. Each navigation request is handled once, so returning to a tab preserves the user's subsequently selected subview.
- Column management, cell inspection, docking, and closing now use icon buttons with Chinese tooltips. Compact vertical padding keeps the controls clear of panel boundaries.
- Ordinary text uses an explicit plain-text language based on field metadata. Brackets, JSON-like text, and previously selected languages no longer trigger JSON validation. Actual JSON fields and MongoDB documents retain JSON mode. Explicitly formatting valid JSON within text changes whitespace while preserving large integers and original numeric representations.
