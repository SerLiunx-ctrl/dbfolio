# DBFolio 1.0.0-alpha.22

## 列宽拖动修复

- 取消表数据和查询结果数据列的最小宽度限制，数值、状态、文本和长文本列均可手动自由缩窄。
- 初始列宽继续根据字段和内容估算；手动拖动后，刷新数据保留调整结果。
- MySQL、PostgreSQL、SQLite 及所有使用共用查询结果网格的入口保持一致。

## 验证与交付

- TypeScript 与真实组件回归通过：两类网格四类字段可拖到约 16 像素，重新拉宽及刷新保留通过。
- 正式 NSIS 安装包、完整便携目录/ZIP 已生成；双包真实启动和前端 IPC、签名/篡改拒绝及 107 条 SHA256 校验通过，ZIP 105 个文件和双包 101 个 web 资源一致。
- 本版尚未公开发布，公开预览通道保持 alpha.21。
