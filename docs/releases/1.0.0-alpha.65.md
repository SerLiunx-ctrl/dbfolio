# 1.0.0-alpha.65

## 中文

- Windows x64 安装包与完整便携版由 GitHub Actions 构建。在线更新继续使用现有签名，发布后逐项验证公开下载，再更新预览通道。
- GitHub Actions 支持生成 Apple Silicon 和 Intel 构建测试包。macOS 的 Developer ID 签名、公证和实机验收仍在准备中，本次 Release 面向 Windows x64。

## English

- GitHub Actions builds the Windows x64 installer and the complete portable edition. Online updates retain the existing signing key. The preview feed moves forward after the public downloads pass verification.
- GitHub Actions can build test packages for Apple Silicon and Intel. Developer ID signing, Apple notarization, and interactive Mac testing are pending. This release distributes Windows x64 packages.
