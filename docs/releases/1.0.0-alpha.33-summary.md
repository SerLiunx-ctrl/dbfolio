# DBFolio 1.0.0-alpha.33

## 中文

- **停靠详情**：表数据和查询结果新增按需展开的单元格详情，支持底部/右侧切换、鼠标和键盘调整尺寸、关闭及布局记忆；可连续查看文本、JSON、十六进制和已有图片预览。
- **统一提交**：表数据详情的有效修改与网格编辑统一进入待提交，通过原有变更预览、提交和放弃流程处理，详情不再直接写数据库。保留数值精度、NULL/空字符串及完整原值冲突检查；无效输入会保留并阻止提交。只查看长字段时，完整值仅随当前详情保留，避免连续浏览扩大网格缓存。
- **列管理**：表数据和查询结果支持搜索列名、显示/隐藏、左右冻结、调整顺序和恢复默认；按表或查询列签名保存布局。复制和粘贴跟随当前可见列顺序，隐藏列不占粘贴位置；至少保留一列，字段类型对应的最小列宽规则保持。
- **索引定位**：点击索引中的列名，切换到同表结构页、滚动定位并高亮约三秒；支持鼠标、键盘、特殊字符字段和只读会话。保留未保存的字段修改；无法对应单个字段的索引表达式仍按文本展示。
- **元数据列宽**：结构、索引、外键及新建表草稿支持拖动表头分隔线调整列宽，超宽时横向滚动，内容裁切在本列内。按引擎和表格类别记住宽度，支持方向键微调、双击或 Home 恢复，以及拖动取消；缩放后保持对齐和紧凑行高。
- **首选项导航**：分类标题与菜单项通过分隔线、缩进、功能图标及文字层级区分，暗色和 OLED 下更易辨认。移除选中项左侧的常驻强调色边线，保留选中背景、加粗和键盘焦点提示。
- **JSON 编辑器**：修复工作线程分派，避免查看、格式化 JSON 时出现后台方法缺失错误。
- **适用范围**：MySQL、PostgreSQL、SQLite 共用交互，新建表草稿与只读状态按能力适配；无可靠主键、扩展类型和截断查询结果保留适用的只读限制，查询结果不推断来源表进行完整值补读。便携版仍须完整解压，EXE 与同目录 web 资源配套使用。
- **维护规范**：记录构建缓存检查和清理规则、统一的提交类型，以及双语发布说明、可点击提交记录和 Full Changelog 规则。

验证：三引擎真实界面组件、提交预览联调、主题/缩放、列布局和图片/数值回归通过；正式安装包与便携版资源、启动、SHA256 和更新签名验证通过。完整安装跨版本升级仍待专项验收，本版没有将该路线图项标为完成。

## English

- **Docked inspector:** Table data and query results now have an on-demand cell inspector. Dock it at the bottom or right, resize it with the mouse or keyboard, close it, and retain its layout. Browse text, JSON, hexadecimal values, and existing image previews continuously.
- **Unified submission:** Valid inspector edits in table data join the same pending changes as inline edits and use the existing preview, commit, and discard workflow instead of writing directly. Numeric precision, NULL versus empty strings, and complete-original conflict checks are preserved. Invalid input remains visible and blocks submission. Viewing a large cell retains its full value only in the active inspector, preventing browsing from continually expanding the grid cache.
- **Column management:** Both grids support column search, visibility, left/right pinning, reordering, and restoring defaults. Layouts are saved by table or query-column signature. Copy and paste follow the visible column order; hidden columns do not consume paste positions. At least one column remains visible, and existing type-based minimum widths are retained.
- **Index navigation:** Click an index column name to open the same table's Structure tab, scroll to the matching field, and highlight it for about three seconds. Mouse, keyboard, special-character names, and read-only sessions are supported. Unsaved field edits are preserved; index expressions without a matching field remain plain text.
- **Metadata column widths:** Structure, Indexes, Foreign Keys, and new-table drafts support draggable header dividers and horizontal scrolling. Content stays within its column. Widths are remembered by engine and table category. Use the arrow keys for fine adjustments, double-click or Home to restore defaults, or cancel a drag. Scaled interfaces retain aligned columns and compact headers.
- **Preferences navigation:** Dividers, indentation, icons, and text hierarchy distinguish category headings from clickable items, including in dark and OLED themes. The permanent left accent line on selected items has been removed while selected backgrounds, bold text, and keyboard focus indicators remain.
- **JSON editor:** Fixed worker routing to prevent missing-method errors when viewing and formatting JSON.
- **Compatibility:** MySQL, PostgreSQL, and SQLite share these interactions, with new-table drafts and read-only states adapted to their capabilities. Rows without reliable primary keys, extension types, and truncated query results retain applicable editing restrictions. Query results never infer a source table for full-value retrieval. Portable builds must still be extracted completely, keeping the EXE and matching web directory together.
- **Maintenance rules:** Recorded build-cache inspection and cleanup requirements, consistent commit types, and bilingual release notes with linked commits and a Full Changelog.

Validation covered real UI components for all three engines, submission-preview integration, themes/scaling, column layouts, and image/numeric regressions. Installer and portable resources, startup, SHA256 checksums, and updater signatures passed. Full cross-version installer upgrade verification remains pending and has not been marked complete on the roadmap.
