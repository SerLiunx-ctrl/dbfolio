# DBFolio 1.0.0-alpha.27

## 列名与数据类型区分

- 索引列表中的列名使用正文颜色，数据类型改为带淡底色和细描边的彩色小标签，便于快速区分。
- 外键本地列/引用列及建表草稿使用相同展示，保持单行紧凑排布；DESC 后缀和完整内容悬浮提示保留。
- 包含此前的 PostgreSQL 结构兼容、字段类型列宽、会话定位与 SQL 补全修复。
