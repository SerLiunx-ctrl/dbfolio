# alpha.35 界面反馈验收

日期：2026-10-28。范围：表操作展开、结构编辑高度、详情数值误报、Redis 数据库计数刷新。

## 专项验证

- MySQL、PostgreSQL、SQLite × 浅色/暗色/OLED × 100%/200%：表页头操作直接可见；结构字段名输入和类型下拉激活前后行高稳定，中文编辑和文字行高/内边距容纳检查通过。
- 三引擎详情：文本修改后切换整数、小数、主键和 NULL，无错误提示、不发起文本完整值请求；原有类型化提交和无效输入保护回归通过。时间类型同样直接使用已加载值；文本/JSON/二进制仍保留按需读取。
- Redis 真实组件与对象浏览器联调：初始、搜索、刷新后显示服务器计数（125→250→3），仅扫描一条匹配键，未把匹配数量当总数；计数失败保留缓存和键列表。新建/删除/重命名沿用重置扫描刷新入口。
- 根因：原详情补读未限定字段类型，MySQL/SQLite 文本接口无法解码数值时返回空，被误判为行不存在；Redis 重置扫描未同步对象浏览器数据库元数据。

## 验证方式与边界

scripts/check-ui-feedback-alpha35.cjs 使用真实 React、Fluent、AG Grid、Monaco 和隔离 IPC，未连接或修改用户数据库。Redis 错误用例隔离连接健康回调，单独核对计数刷新失败时缓存保留；实际断线仍遵循既有连接状态机制。
