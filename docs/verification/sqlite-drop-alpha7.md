# SQLite 文件拖入快速建会话验收

版本：1.0.0-alpha.7；日期：2026-09-29。

## 功能与边界

- 拖入窗口打开新建会话，SQLite 类型、原始文件路径及文件名自动填充；新建表单内也可拖入。点击保存才创建会话，不自动连接、不复制文件、不写入数据库。
- 名称使用去掉常见 SQLite 扩展名的文件名；无扩展名或其他扩展名仍按 SQLite 文件头识别。与现有名称冲突时追加编号，用户手动输入的名称优先保留。
- 后端只读检查前 100 字节的 SQLite 标识和页大小，规范化绝对路径；拒绝目录、相对路径、不存在/无法读取、空白/加密/错误文件。不把文件头识别称为完整数据库完整性检查；需连接后查看实际内容。
- 一次一个文件；正在编辑已有会话、复制会话、连接测试、保存或其他对话框时拒绝覆盖。文件识别期间只处理一个请求；编辑上下文变化时忽略旧结果，取消不保存，失败保留输入。
- 启用 Tauri 原生文件拖放；标签页排序改为指针拖动，保留移动阈值、插入标记、点击选择、关闭按钮及取消行为，以兼容 Windows 原生文件拖入。原有浏览器文件导航保护保留。

- 前端 TypeScript / Vite 构建通过。
- `scripts/check-sqlite-drop.cjs`：浅色/OLED、自动填入、名称重复、中文路径、手动名称保留、保存/取消/失败、编辑保护、多文件/无效文件、上下文变化、内部拖动隔离和标签排序/点击/关闭通过。
- 真实桌面 Tauri 事件通道、Rust 文件头识别及中文绝对路径填表/模拟会话保存联调通过，测试前后原文件字节一致。拖放事件由测试注入，未自动执行操作系统文件管理器鼠标拖动；会话保存模拟，未向用户配置库增加测试会话。
