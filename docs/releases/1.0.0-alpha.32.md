# DBFolio 1.0.0-alpha.32

## 中文

- 结构、索引和外键表格支持拖动表头分隔线调整列宽，超出可视区域时可横向滚动，长内容不会覆盖相邻列。
- MySQL、PostgreSQL、SQLite 及新建表草稿使用统一交互，按引擎和表格类别记住列宽，刷新或切页后继续保留。
- 支持左右方向键微调、双击恢复默认宽度，以及拖动取消；界面缩放后保持表头与单元格对齐和紧凑行高。原有行内编辑和索引列定位保持可用。

## English

- Resize columns in Structure, Indexes, and Foreign Keys by dragging header dividers. Wide tables scroll horizontally, and long content stays within its own cell.
- MySQL, PostgreSQL, SQLite, and new-table drafts share the same interaction. Column widths are remembered by engine and table category across refreshes and view changes.
- Use the arrow keys for fine adjustments or double-click to restore the default width. Resizing can be cancelled, and scaled interfaces retain aligned columns and compact headers. Inline editing and index-to-field navigation remain available.
