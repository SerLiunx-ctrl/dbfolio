# DBFolio 1.0.0-alpha.41

## 中文

- 新增 MySQL、PostgreSQL、SQLite 共用的 ER 关系图标签页，可从数据库概览、数据库或表的右键菜单、表页工具栏进入。支持选表、搜索、拖动、缩放、自动布局、字段折叠，以及打开表或定位结构字段。
- 区分真实外键和本地业务关联，支持复合字段配对、自引用及 PostgreSQL 跨 schema 同名表；查看关联两端字段和删除/更新规则。布局与标注可保存在本地，保存失败保留草稿。
- 支持 SVG、PNG 和 Mermaid 导出。大库按范围加载元数据，未加载或无权限引用明确提示；图仅表达当前发现范围，业务标注不修改数据库。首版每会话数据库一份布局，配置迁移暂未专门接入图配置。
- PostgreSQL 已通过模型和界面矩阵验证；因本机服务不可用，用户确认真实 PostgreSQL 验收后补，R07 暂不标记全部完成。
- 本版未修复锁屏识别缺陷，也未将完整跨版本升级标记为已验收。

## English

- Added a shared ER diagram tab for MySQL, PostgreSQL, and SQLite, accessible from database overviews, database/table context menus, and table toolbars. Select tables, search, drag, zoom, arrange, collapse fields, open tables, and jump to highlighted structure columns.
- Distinguished real foreign keys from local business annotations, including composite column pairs, self-references, and same-named tables across PostgreSQL schemas. Inspect both ends and update/delete rules. Save layouts and annotations locally; failed saves retain pending changes.
- Export the displayed scope as SVG, PNG, or Mermaid. Large catalogs load metadata by scope, with explicit unavailable-reference states. Diagrams represent the currently discovered scope; annotations do not modify the database. The first version stores one layout per session/database; configuration migration does not yet specifically include diagram settings.
- PostgreSQL passed model and UI matrix checks. Its live-server acceptance is deferred at the user’s request because the local service is unavailable; R07 is not marked fully complete.
- This release does not fix lock-state detection or mark full cross-version upgrade acceptance as complete.
