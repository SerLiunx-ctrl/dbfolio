# v0.110：AI 响应查看

## 本次变化

- 旧版将 SSE 事件包装和心跳一起计入 2 MiB，因此实际 AI 正文很小时也可能超限。现在 SSE 传输最多 32 MiB，AI 正文最多 2 MiB；普通非流式 HTTP 响应仍最多 2 MiB。
- 数据生成失败提示、原因弹窗和生成过程里都有“查看 AI 响应”入口。选择具体批次后可分页浏览与复制保留的正文，包括非法 JSON、HTTP 错误和超限前收到的内容。
- 查看器展示 HTTP 状态、传输大小、正文大小及截断提示。返回正文不代表通过校验，更不代表已经写入数据库。

## 自行验收

1. 使用既有 AI 配置生成少量数据，在过程面板打开“查看 / 复制 AI 响应”，检查批次、正文和复制结果。
2. 若生成失败，在页面错误条点击“查看 AI 响应”，检查失败请求收到的正文；先前成功的批次也可从下拉框切换。
3. 生成过程中取消，查看已接收内容。若连接尚未返回正文，会明确显示没有正文，不伪造结果。
4. 检查超限响应的“仅为已保留的部分”提示；长响应通过“上一段 / 下一段”浏览，不把完整大文本一次性渲染到界面。

## 边界与自动验证

- 本轮仅在数据生成中归档响应；规则建议沿用原流程。只保存当前打开页面的内存现场，重新生成或关闭页面后清除，无法恢复旧版本丢弃的响应。
- 最多保留最近 20 批、约 8 MiB 文本内存；超过后移除早期批次并显示提示。服务推理字段和正常 SSE 包装不归档。
- TypeScript/Vite 构建、前端归档/生成回归通过。Rust 57 项通过，4 项服务器集成测试跳过；使用本地模拟 HTTP 验证传输开销、正文上限、错误正文和当前请求密钥隐藏。
- 未调用真实计费模型，未控制或启动桌面程序。
