# DBFolio 1.0.0-alpha.28

## 服务器类型能力与中文说明

- 字段类型从服务器能力获取，MySQL 按版本筛选；PostgreSQL 按当前数据库实际注册的内置、扩展和自定义类型提供选项。
- 已启用 pgvector 时提供 vector、halfvec、sparsevec，并允许填写维度；兼容非 public Schema，标注扩展及版本。
- 类型名称后增加中文用途说明，例如 `varchar · 可变长度字符串`；说明和 SQL 值分离。
- 新增列、行内修改、新建表和旧字段编辑入口共用目录，提供“刷新类型”，切库/重连重新读取。读取失败明确显示未核验，不猜测扩展已安装，保留当前字段声明。
- 保留此前的元数据类型标签、PostgreSQL 结构兼容、字段类型列宽、会话定位和 SQL 补全修复。

## 验证与交付

- PG17 / pgvector 0.8.0、PG18 / pgvector 0.8.5 的隔离实库通过：跨库安装隔离、限定 Schema、三类向量维度建表/回读、移除扩展、枚举和域发现。
