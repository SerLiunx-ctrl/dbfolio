# DBFolio 1.0.0-alpha.35

## 中文

- 表页头直接展示触发器、新建查询、新建分析、数据生成与刷新；按数据库能力显示对应操作。
- 结构编辑输入框和下拉框统一外框、文字行高与内边距，展示和编辑保持稳定行高；MySQL、PostgreSQL、SQLite 及建表草稿一致适配。
- 修复单元格详情切换数值、时间和 NULL 字段时误报目标行不存在；这些完整值直接使用网格数据，文本、JSON 和二进制保留按需补读及编辑保护。
- Redis 搜索、刷新和键操作重新扫描后同步服务器数据库计数，不用筛选结果或扫描页数量代替总数。

## English

- Table headers expose triggers, new queries, analysis, data generation, and refresh directly, subject to database capabilities.
- Structure editors align control bounds, text line height, and padding with stable display/edit row heights across MySQL, PostgreSQL, SQLite, and table drafts.
- Fixed false missing-row errors when inspecting numeric, temporal, and NULL fields. Complete values use grid data while text, JSON, and binary retain on-demand loading and edit protection.
- Redis searches, refreshes, and key operations refresh server database counts after restarting scans. Filtered results and scan page sizes are not treated as total counts.
