# v0.85 自行验收清单

本轮只进行代码检查、自动测试与打包，不控制电脑，不启动/关闭工作台，不连接业务数据库。请自行关闭旧版本后运行 `release/Data Workbench v0.85.exe`。

## 连接与编辑保留

1. 连接测试会话：列表先显示“连接中”，成功显示“已连接”；认证/网络失败显示“已断开”，可重试。
2. 在 SQL、表格、Redis 中分别留下尚未提交的编辑。自行暂时断开测试数据库的网络或停止测试服务；等待空闲探测（约 30 秒加最多 5 秒），或执行一次读取触发探测。
3. 确认页签和编辑内容仍在，顶部出现断线提示；恢复服务，点击“重新连接”，确认编辑保留且没有自动执行 SQL/提交数据。
4. 在 SQL 中输入语法错误：任务显示失败；如果 ping 正常，会话仍为“已连接”。

## 统一任务状态

1. 分别执行查询、导入、导出、同步比较和同步执行，查看底栏“任务中心”：名称、会话、耗时、进度/已处理量、成功或失败结果一致。
2. 在测试表导入较大 CSV，或同步到测试库；点击弹窗里的“取消任务”，先显示“等待停止”，结束后保留已提交数量。取消前已提交的批次不会撤销；同步的回滚目录仍能查看。
3. 导出到已有文件并中途取消，确认原文件内容不变、没有遗留临时文件；完成导出时则得到有效文件。
4. 同时打开两个查询，在任务中心选择其中一个取消，确认另一个未被取消。单个查询页的取消按钮遇到多个并行查询时，会提示到任务中心明确选择。
5. 任务尚在运行时关闭主窗口：应提示等待或在任务中心取消；任务结束后可正常关闭。

前端生产构建通过；Rust `cargo test --lib --offline` 共 14 项通过、0 失败、2 项依赖真实数据库的测试按默认配置忽略。

- `node scripts/check-runtime.cjs`：连接请求去重、失败重试、断线探测、过期探测结果隔离；取消等待真实返回、部分提交数量、部分失败、完成/取消竞争、任务释放。

- Rust 临时 SQLite 测试：同步取消后只保留已提交批次，提交数量与实际行数一致；原有回滚与批次边界测试。
- Rust 导出文件测试：中断时原文件保留且临时文件移除；完成时替换为有效 JSON。

## 当前限制

- SQLite 当前查询不能立即中断，界面提示等待；写入取消在批次/语句之间生效。网络长时间不返回时，写入可能需要继续等待并核对实际提交状态。
- 未知总量不会显示虚构百分比；任务记录只保留本次运行，不承诺程序崩溃后的结果恢复。
- 本轮未进行 MySQL/PostgreSQL/Redis 真实断网测试和桌面交互测试。
