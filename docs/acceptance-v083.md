## 发现的体验问题

1. **重启未恢复窗口位置与最大化状态**：副屏最大化退出后，重启回到主屏普通窗口，需要手动移回副屏。
2. **添加行缺少定位反馈**：表格已有 200 行时，新空行追加在末尾，没有自动滚动/聚焦；当前视口看起来没有反应。空行全为 NULL 时不计入待提交变更，与实际输入后的修改区分处理。
3. **高缩放下详情需横向滚动**：200% 配合 1280×800 窗口时三栏无法同时显示。当前有横向滚动兜底，后续可增加折叠前缀树/详情抽屉等窄屏布局。
4. **集合编辑后浏览位置丢失**：List 保存后重载回首批 100 项，深处成员需重新加载；索引写入正确，但连续编辑体验仍可优化。
