# DBFolio 1.0.0-alpha.38

## 中文

- 表数据浏览与 SQL 查询结果支持 Ctrl+F（也可点击查找图标），查找当前已加载数据的可见列。匹配单元格高亮并显示数量，Enter/Shift+Enter 或上下按钮循环定位，Esc 关闭。大小写不敏感，按文字匹配，不执行正则表达式。
- 查找不查询数据库、不改变服务器筛选、选中行或待提交编辑；刷新、排序、列显隐和编辑后重算匹配。截断值仅查找已加载部分，SQL 与单元格文本编辑器保留自身 Ctrl+F。

## English

- Table browsing and SQL results support Ctrl+F or the search icon to find text in visible columns of currently loaded data. Matching cells are highlighted and counted; Enter/Shift+Enter or the arrow buttons cycle through matches, and Escape closes search. Matching is case-insensitive literal text, not regular expressions.
- Search does not query the database or change server filters, row selection, or pending edits. Matches update after refreshes, sorting, column visibility changes, and edits. Truncated values are searched only within their loaded portions. SQL and cell text editors retain their own Ctrl+F behavior.
