数据库操作

SQL 查询与表格编辑
补全表名和字段，执行选区 SQL，查看历史和执行计划。编辑数据后可先核对逐行差异及 SQL，再勾选要提交的行。
表结构与数据字典
查看字段、索引、外键和 DDL，从 ER 图定位关联字段。可给数据字典补充业务说明，并导出 Markdown、HTML 或 Excel。
测试数据与文件
用规则、模板或 AI 生成测试数据，预览后写入或导出。支持 CSV、TSV 导入及 CSV、JSON、Excel 导出，适用引擎可处理 SQL 文件。
数据与结构同步
比较受支持的同引擎数据库，核对差异与同步计划再执行。导入、导出和同步的进度可在任务中心查看。
连接与会话管理
按项目和环境管理连接，生产会话默认只读，适用连接可配置 SSH 和 TLS。会话配置保存在本机，使用客户端无需注册。

AI 与数据分析

编写 SQL 与识别关联

描述查询需求，用 @ 引用表或字段。生成的 SQL 供你在编辑器中审阅和执行，也可以优化选中的语句。

ER 图可以根据所选表结构建议关联，审阅后可加为业务标注。AI 服务和模型由你配置，按需启用。

从查询结果绘图

从 SQL 查询或 MongoDB 聚合结果选择分类、数值和聚合方式，查看图表、分类明细和字段概况。

有柱形图、折线图、环形图、散点图和指标卡等 9 种展示。分析方案可保存并重新运行，结果可导出为 PNG、CSV 或 JSON。
