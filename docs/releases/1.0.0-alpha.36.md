# DBFolio 1.0.0-alpha.36

## 中文

- 数据网格用焦点描边、选中背景、修改单元格标记及新增/删除行边线区分状态。
- 结构字段类型支持按名称和说明搜索；收起仅显示类型名称，选项分开显示说明，保留服务器发现和能力限制。
- 单元格详情工具栏固定，编辑区跟随面板伸缩，显示只读、可编辑、输入错误和已修改待提交状态。
- Redis 区分服务器总键数、已加载键数、当前前缀筛选数量及扫描完成状态；尚未加载完时提示继续扫描。

## English

- Data grids distinguish focus, selected rows, modified cells, and new/deleted rows using outlines, backgrounds, and markers.
- Structure field types support searching names and descriptions, show concise selected names and separate option descriptions, and preserve server-discovered capability limits.
- Cell inspection keeps tools fixed while the editor follows panel resizing, with explicit read-only, editable, invalid-input, and pending-change states.
- Redis distinguishes server totals, loaded keys, current prefix-filter results, and scan completion, with continuation guidance for incomplete scans.
