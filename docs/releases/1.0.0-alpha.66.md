# 1.0.0-alpha.66

## 中文

- 查询历史改用表格显示 SQL 摘要、连接、执行结果和耗时。详情使用与查询编辑器一致的高亮查看完整 SQL，支持复制和重新打开。可删除单条本机历史，已收藏的 SQL 仍可查看。
- 移除数据页的截断预览提示，单元格详情仍可查看完整值。拉开快速打开中搜索框与对象加载范围控件的间距。
- 「关于 DBFolio」精简为版本和项目信息，移除累积的历史更新日志。

## English

- Query history now uses a table with SQL previews, connections, results, and execution times. Open a record to view the complete SQL with the same highlighting as the query editor, copy it, or reopen it in a new tab. You can delete individual local history records while keeping their saved favorites.
- Removed the truncated-preview notice from the data view. Cell details still offer access to the complete value. Quick Open now has more space between the search field and the object scope selector.
- About DBFolio shows the version and project information in a compact layout.
