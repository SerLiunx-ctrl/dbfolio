# 数据分析 A1＋A2 自行验收（v0.117）

本版本不自动执行分析查询、不上传分析数据到 AI 服务。请在测试连接上自行验收。

## 0. 独立新建分析（推荐入口）

1. 无需执行普通查询，点击底部「数据分析」（欢迎页、工作区菜单也可进入）。选择会话及数据库，点击「新建分析」。
2. 应打开独立编辑页，尚无结果，手动填写 SQL 或 MongoDB 聚合管道后点击「执行 / 刷新分析」才读取数据。
3. 表/视图页点击「新建分析」，应预填该表 SQL；集合页点击同名按钮，应预填数据库与集合。两者不继承当前列表筛选或数据。
4. 检查原页面保持原状；另一个会话的页签仍在时，分析入口不得把它的数据库带入当前会话。Redis 不应作为可选分析会话。

## 1. 从 SQL 结果绘图（快捷入口）

1. 执行一条有分类和数值的 SQL，例如 MySQL / PG / SQLite 均可执行：

   ```sql
   SELECT '一月' AS period, 120 AS amount, '线上' AS channel
   UNION ALL SELECT '二月', 180, '线上'
   UNION ALL SELECT '一月', 90, '线下'
   UNION ALL SELECT '二月', 140, '线下'
   ```

2. 点击结果工具栏「用此结果绘图」，应打开新页签，提示「当前查询页、非全量」。
3. 分类选择 period，数值选择 amount，分组系列选择 channel。切换柱状、条形、折线和面积图，检查求和与平均值。
4. 切换指标卡，应合计 530；切换直方图检查频数总和 4。散点需要两个数值字段，可另查 `SELECT 1 AS x, 2 AS y UNION ALL SELECT 2, 5`。
5. 在数据页检查分页与横向滚动；字段概况检查非空数、不同值、最小/最大/平均。
6. 点击「执行 / 刷新分析」，范围应变为重新执行的查询结果；超过 5000 行应明确提示受限。查询等于 5000 行但不存在第 5001 行时，不应误报截断。

## 2. 保存方案与参数

1. 展开「数据源与参数」，将 SQL 改为 `SELECT :start_date AS period, :amount AS amount`。
2. start_date 选择文本或日期，amount 选择数值；填写值并执行。
3. 修改参数后，旧图表保持显示并出现待刷新提示；刷新失败时应显示错误并保留旧结果。
4. 命名后点击保存；从「分析库」重新打开，应恢复 SQL、参数、配置，直到点击执行才查询。
5. 检查另存副本、删除确认、关闭未保存方案提醒。重启后页签草稿应恢复，但结果不恢复、查询不自动执行。

## 3. MongoDB

1. 集合工具 → 聚合管道，运行已有只读管道；在结果中点击「用此结果绘图」。
2. 或从工作区菜单 → 数据分析与图表，选择 MongoDB 会话，新建并填写数据库、集合。
3. 使用包含 `$group` 的管道生成分类及数值结果，检查数值类型和嵌套字段。
4. 参数使用值占位符，例如 `[{"$match":{"status":":status"}},{"$group":{"_id":"$category","count":{"$sum":1}}}]`。类型为数值的参数传递为 BSON Decimal128；不要把占位符写在字段名中。
5. 大于 500 条或 8 MiB 时应提示受限；包含 `$out` / `$merge` 等写入阶段应被拒绝。

## 4. 导出与窗口

- PNG：应包含图表及数据范围；分组超过显示上限时有裁剪说明。
- 图表 CSV：是当前图表聚合数据，含范围与采集时间；JSON：规范化数据及来源/配置信息。
- 深浅色切换、调整侧栏及窗口宽度后，图表应跟随尺寸，窄窗口配置自动换行、表格内部滚动。
- 查询时任务中心可查看运行状态和取消；失败后错误醒目，原结果保留。SQLite 正在执行的语句可能需要等待结束。

## 5. 字段备注与名称关联

1. 从文章表新建分析并执行，轴字段选择应显示数据库中的字段备注。旧方案或自定义查询可展开「字段备注与名称关联」，加载表列表，选择「字段备注来源表」并刷新。
2. 以 category_id 为分类、记录数为聚合，选择饼图；在名称关联中选择 category_id → 分类表 → id → name，然后「应用配置并刷新分析」。
3. 分类轴应自动选择新增名称列；数据页保留原始 category_id。匹配失败显示 ID 并提醒；不同 ID 同名应分开统计；同一 ID 对应不同名称时应保留原图并报错。
4. 保存方案、关闭再打开，关联配置应仍存在；点击执行后才重新加载结果与名称表。
5. 饼/环图标签与图例显示百分比；图例支持搜索和滚动，搜索不减少扇区或改变占比。分类多时小扇区的外部标签隐藏，可在明细查看。调整窗口宽度，图例应自动移到下方。
6. 搜索图例后导出 PNG，图片仍包含全部当前展示分类的图例；Top N 未显示的分类仍不计入占比。

## 本轮边界

- SQL 最多 5000 行，MongoDB 最多 500 条 / 8 MiB；大数据应先在数据库聚合，再画图。
- 每张图一个数值字段，支持分类分系列；日期分桶写在 SQL / 管道中。
- 不接入 Redis、不支持跨连接联表、AI 分析和多图仪表盘。
- 图表数值为浮点近似，不用于精确财务计算。超出安全范围的整数保留文本并排除绘图；旧查询页中已经丢失精度的整数需重新执行分析。
